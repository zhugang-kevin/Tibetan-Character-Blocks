# brand/ — 「藏趣」品牌资产

**符号：牦牛头**（无文字）。
选它的理由：哈达、经幡、转经筒、八吉祥都带宗教属性，国宗发〔2017〕88 号第 2 条禁止以佛教道教名义进行商业宣传，做主符号风险太高；**牦牛是纯世俗的藏地符号**，全球辨识度高，轮廓简洁，缩到 48px 仍认得出。

生成命令（可复现，改参数全套重出）：

```bash
python scripts/make-brand-assets.py
```

## 源文件

- `src/` 里是 AI 生成的牦牛原稿（纯白底、无水印）。**只作生成源，不要直接对外用。**
- 交付用 `brand/*.png`，已做：白底抠图（保留抗锯齿）→ 统一品牌金 → 强制左右对称 → 合进图标底版。

## 注意

1. **不要加文字**（用户要求）。要加字另做「锁版」变体，别改这套。
2. `brand/` 已加进 `project.config.json` 的 `packOptions.ignore`，**不进小程序包**（主包预算只剩 ~2KB 余量，别塞进去）。
3. 小程序头像上传用 `logo-200.png`；官方要求正方形、≥144×144、不能带二维码/联系方式。

# 隐私保护指引 · MP 后台填写稿（可粘贴）

> 配套 `docs/privacy-policy-draft.md`。MP 后台字段名会随版本变化，按**数据类型**对应；
> 选择题按实际选项勾选。这是一份**填写稿**，不是法律意见；发布前让法务/主体确认。

## 1. 收集的信息（逐项）

### 1.1 微信 openid
- 收集方式：用户使用支付 / 同步 / 收礼时，`wx.login` 产生一次性 code，服务端换取 openid。
- 用途：账号归属、虚拟支付下单、礼物发货、跨设备进度。
- 是否必填：仅上述功能需要；纯本地玩法不需要。
- 说明：openid **不下发前端**；前端只传匿名 uid。

### 1.2 订单信息
- 字段：订单号、商品 id、金额、支付状态、时间。
- 用途：下单、发货、对账、退款、客服。
- 是否必填：仅打赏/虚拟支付时。
- 共享：微信支付/米大师（**开通后**）。

### 1.3 用户提交的信息
- 字段：祝福语、署名、给收礼人取的名字。
- 用途：随礼物展示。
- 是否必填：否（用户自愿填写）。
- 说明：不要填写真实姓名/手机号等身份信息。

### 1.4 设备信息（匿名遥测）
- 字段：随机 sessionId、版本号、事件类型、计数、Q1 题序种子。
- 用途：崩溃/异常诊断、Q1 识认率聚合统计。
- 是否必填：自动；**不含** IP/IMEI/位置/通讯录。
- 共享：无第三方广告 SDK（仅微信官方广告组件）、无第三方统计 SDK。

### 1.5 本地存储
- 字段：课程/关卡进度、星级、证书、签到、看过的文化卡、收礼记录、匿名 uid。
- 用途：本机玩法与进度。
- 说明：默认仅本机；开启同步后才上传进度 JSON。

### 1.6 广告（不由我们收集）

- 组件：**微信官方广告组件**（结算页 `<ad>` 视频/横幅、游戏页激励视频），**无第三方广告 SDK**。
- 我们收到的：**只有「是否完整看完」一个布尔值**（用于决定给不给一次游戏内提示）。
- 我们不获取、不存储：广告标识、兴趣画像、点击行为。
- 是否必填：**无需勾选**（不属于我们收集的数据）；但**隐私指引正文必须写明广告**，否则与实际不符。
- 是否展示：**以 `config/ads.js` 为准**（未配置 → 不展示）。填表前跑 `node scripts/ads-readiness.js` 核对，
  **不要照抄任何历史状态**（ID 一填，旧状态就是假话）。

## 2. 不收集（不要勾选）

位置、相机、麦克风、通讯录、手机号、身份证、收货地址、微信昵称/头像。
（礼物署名/取名是用户自愿输入的展示文本，不是身份信息。）

## 3. 保存期限（按实际能力填）

| 数据 | 期限 | 现状 |
|---|---|---|
| 本地进度 | 直到用户清空/卸载 | 已实现 |
| 服务端进度/礼物 | 直到用户申请删除 | 已实现（需提供删除入口/邮箱） |
| 订单 | 按法律法规/支付渠道要求 | 开通支付后确定 |
| 匿名遥测 | **建议 180 天** | ⚠️ 代码未自动清理，发布前补或改为只留聚合 |

## 4. 第三方共享

- 微信支付/米大师：**仅在开通虚拟支付后**，用于扣款与对账。
- 服务器托管服务商（境内）：受托存储。
- **不出售**；无第三方广告 SDK（仅微信官方广告组件）；无法定情形不对外提供。

## 5. 用户权利

- 查看/更正：小程序内查看进度；本地可"清空进度"。
- 删除：本地一键清空；服务端删除/注销通过【联系邮箱】申请。
- 撤回：停止使用/关闭授权；不影响此前处理。
- 答复时限：【X】个工作日。

## 6. 未成年人

- 不主动面向 14 周岁以下儿童；不收集其身份信息；不做定向投放
  （广告由微信官方组件按平台规则展示，我们无法识别年龄，故不承诺"零广告"）。
- 监护人可联系删除。

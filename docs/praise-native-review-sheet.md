> **用途**：`data/praise.js` 中 25 条夸赞短语的母语者终审签确表。
> **机器角色**：仅做"去伪"——逐字核对藏文拼写是否合法、释义是否与中文对应。
> **人类角色（你）**：在「母语者签确」栏打 ✓ 或写出正确藏文。机器**不会**把 `pendingNativeReview` 翻 false，
>   必须由人耳终审通过后才由人工翻转（防假绿，B5 关卡）。
>
> **✦ 语义层状态（2026-10-13 用户人工确认）**：用户已校对并确认——**若文案直接对接游戏，这 25 条藏文翻译均准确**。
>   即语义层已获母语者/用户人工签确；剩余未决的是**读音层**（见 `praise-pronunciation-sheet.md`）。
>   `pendingNativeReview` 仍 `true`（语义+读音两层全签确后由人工翻转）。
>
> **核对方法**：每条藏文拆成成分词，逐一对照权威词典（Wiktionary / Rangjung Yeshe Wiki / THL / Gosok Rinpoche / 84000 / DILA / WisdomLib），确认"拼写合法 + 义项与中文一致"。
> **结论口径**：✓ = 机器核对无矛盾；⚠ = 机器核对无错但**弱译/意译**（藏文成立，但比中文成语弱或偏字面，建议母语者留意是否要更地道说法）。

# 无提示识认测试 · 协议（Q1 / D148）

> 目的：把「30 天识认 30 辅音」从一句口号变成**可计算、可复现**的指标。
> 代码口径：`scripts/lib/recognition.js`；门禁：`scripts/test-recognition.js`（9/0）。

## 1. 测什么

- **对象**：30 个藏文辅音（`data/learning.js → CONSONANTS`，30 个）。
- **题量**：30 题，每个辅音恰好出现一次，**随机顺序**。
- **题型**：四选一（4AFC）——显示一个藏文字母，四个候选（中文音/罗马音），选一个。
- **无提示**：不显示颜色、不显示配对提示、**不播发音**、不显示同组字母。
- **时长**：不限时（限时会混入"反应速度"，不是识认本身）。

## 2. 怎么算

| 项 | 规则 |
|---|---|
| 有效题数 | 只有 **未使用提示** 的题计入分母 |
| 单轮正确率 | 有效题中答对的比例 |
| 单轮达标 | 有效题 ≥ 30 **且** 正确率 ≥ 80%（24/30） |
| 样本量 | 完成 30 天课程、且完成测试的用户；**n ≥ 30** 才报"达标率" |
| 样本不足 | n < 30 只报**均值**与分布，不宣称达成 |
| 场次过滤 | 有效题 < 30 的场次不计入达标率（不能用 3/3 冒充 100%） |

> "用了提示算对"是最常见的假绿来源：它证明的是"能跟着提示找"，不是"认得"。
> 所以提示题**直接排除出分母**，而不是算错。

## 3. 业务目标（D148）

1. **主指标**：第 30 天无提示识认率 ≥ 80%（30 题、4AFC、无提示）。
2. **文化好感**：3 题 5 点李克特（认同 / 愿意推荐 / 愿意继续了解），目标均值 ≥ 4.0。
3. **唐卡转化**：完成至少一幅**数字**唐卡拼图的用户比例（不涉及实物，D147 后无实物）。

## 4. 已知限制（不粉饰）

- **4AFC 有 25% 猜测基线**：80% 的达标线已明显高于猜测，但仍不是"绝对掌握"；
  更严格的口径是**生产式**（看字母写/说读音）或**听辨**（听音选字母），需要真人录音与评分。
- **样本偏差**：完成 30 天课程的人本身就是高意愿群体，达标率不能外推到全体。
- **母语者核验未做**：题目的"正确读音"仍需懂藏文者逐条确认（Q2 同源问题）。
- **测试界面未做**：当前只有评分口径与门禁；玩家端的测试页是下一步（需要 UI + 埋点 + 隐私说明）。

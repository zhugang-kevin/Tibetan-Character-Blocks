**两个已知待定项**（我会重点看你这两行的意见）：

1. **旺堆 = དབང་འདུས་**：`དབང་` 权 / `འདུས་` 聚，字面偏「权势汇聚」。
   现标词义「福聚」是取其吉意 —— 这个处理**是否合适**请你定。
2. **嘎玛 = སྐར་མ་**：`སྐར་མ` 是「星辰」，而「嘎玛/噶玛」在藏地也常对应 `ཀརྨ`（业）。
   池里写的是「嘎玛」，我按「星辰」这一支取的写法。**若你要的是「业」那一支，写法应改为 ཀརྨ་。**

# 小程序客服开通与验证

> 结论先说：**微信小程序的客服功能不需要审批，也不需要付费。**
> 是**后台配置 + 代码按钮**两件事，配完即可用。
> 我之前说「需要腾讯后台开通」不够准确 —— 准确说法是「需要在小程序后台**添加客服人员**」。

## 二、微信后台操作（5 分钟）

### 2.1 添加客服人员

```
微信公众平台 → 登录小程序
  → 左侧「功能」→「客服」
  → 「添加客服人员」
  → 填入客服的微信号（必须是已实名绑卡的微信）
  → 客服人员微信收到邀请 → 接受
```

**注意**：
- 客服人员**不需要**是管理员
- 一个客服账号可以绑定**多个小程序**（最多 100 个，待核验）
- 客服人员用**微信**接收消息，不是 QQ

### 2.2 确认客服功能已开启

```
「设置」→「基本设置」→「服务类目」
确认已有类目（客服功能依赖类目开通）
```

**待核验**：是否需要特定类目才能使用客服功能。
一般「工具」「教育」类目都可以，但**建议实测**。

### 2.3 消息推送配置（可选，但要自动回复就必须配）

如果要**自动回复**或**把消息转发到自己的服务器**：

```
「开发」→「开发管理」→「开发设置」→「消息推送」
  → 启用
  → URL：https://api.dorjea.cn/wx/message
  → Token：自定义（与服务器一致）
  → EncodingAESKey：随机生成
  → 消息加解密方式：安全模式
```

**但这一步依赖**：
1. 域名已备案（`api.dorjea.cn`）
2. HTTPS 已配置
3. 服务端实现 `/wx/message` 接口

**现阶段（备案未完成）→ 先跳过，只做人工客服。**

## 三、人工客服 vs 自动回复

| 模式 | 需要什么 | 现在能做吗 |
|---|---|---|
| **人工客服**（客服人员在微信里手动回）| 只需 2.1 添加客服人员 | ✅ **立刻能做** |
| 自动回复 / 机器人 | 2.3 消息推送 + 服务端接口 | ❌ 等备案 + 开发 |

**建议先做人工客服** —— 5 分钟配完就能用，不依赖备案。

## 四、验证步骤（配置完必须做）

### 4.1 开发者工具验证

```
1. 微信开发者工具打开项目
2. 编译 → 进入「客服」页
3. 点「联系客服」按钮
4. 应弹出「客服会话」窗口
```

**如果点不动或报错**，常见原因：

| 现象 | 原因 | 解决 |
|---|---|---|
| 按钮点了没反应 | 未添加客服人员 | 回 2.1 |
| 提示「该小程序未开通客服」 | 类目问题或未发布 | 检查服务类目 |
| 提示「暂无客服在线」 | 客服人员未上线 | 客服微信打开「客服小助手」小程序 |
| 真机正常、工具异常 | 工具限制 | 以真机为准 |

### 4.2 真机验证（必须做）

```
1. 手机上打开小程序（体验版即可）
2. 点客服按钮
3. 发一条消息（如「你好」）
4. 客服人员微信应收到「客服小助手」推送
5. 客服回复 → 用户端应收到
```

**只有真机收发通了，才算客服功能可用。**

## 五、客服人员的日常操作

客服人员需要在微信里：

1. 搜索并打开「**客服小助手**」小程序
2. 切换到对应小程序
3. 查看待回复消息
4. 直接回复

**注意**：
- 客服人员**不在线时**用户发的消息会留存，上线后可见
- 但用户端**看不到「客服不在线」的提示** —— 这是微信的默认行为

---

## 六、要不要做「服务通知」？

用户发消息后，客服回复时用户会收到微信「服务通知」。
**这不需要额外配置**，是客服功能的默认行为。

**但**：如果用户关闭了「服务通知」，就收不到 —— 无法强制。

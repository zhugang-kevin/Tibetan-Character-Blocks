## 2. 收银台专项：为什么微信小店这条路很可能走不通

这是本次核查最重要的发现，**证据全部来自微信小店官方规则页原文**。

### 2.1 官方类目表（原文照抄）

《微信小店「二级类目-香道用品」类目管理规则》[^1]，一级类目 `文玩文创` 下，**全部开放的三级类目只有 8 个**：

| 三级类目 | 准入类型 |
|---|---|
| 合香珠 | 开放 |
| 合香牌 | 开放 |
| **沉香**香薰制品 — 燃香 / 香囊·香包 / 精油 | 开放 |
| **檀香**香薰制品 — 燃香 / 香囊·香包 / 精油 | 开放 |

**没有「藏香」「柏香」「复合香」「线香（通用）」这一类。**

### 2.2 标题公式把"材质"锁死在沉香/檀香

同一份规则 4.2.3 规定，**单方燃香**的标题必须写成：
`品牌 + 材质*（沉香 / 檀香）+ 款式 + 商品形制*（线香 / 盘香 / 棒香 / 塔香 / 香粉）+ 重量 + 其他描述`

→ 材质字段只给了 **沉香 / 檀香** 两个选项。

### 2.3 更致命的一条：混合香被明令禁止

同规则 4.1.4「禁止出售和推广的商品」第 (10) 项原文：

> **禁止「混合香」以 燃香 / 香薰精油 / 香包·香囊 的名义出售**

**藏香是典型的多味复合香**（柏木 + 多种藏药香料 + 粘合剂），既不是沉香单方，也不是檀香单方。

### 2.4 换到「家居日用」类目？也不行，而且更糟

《微信小店「一级类目-家居日用」类目管理规则》[^2] 4.1 禁售清单原文包含：

> **涉及封建迷信、宗教、祭祀的相关信息**，包括不限于：佛龛、**佛香**、念佛灯、僧袍、佛牌、阴牌等法器用品……祭祀用品……
>
> 平台/类目禁止售卖或未开放的商品，包括不限于：(1) 以线香、盘香、香粉、精油等形态呈现的成分为沉香、龙涎香的**单方香**商品，**及平台未开放的香薰香道类商品**……

→ 一层是**"佛香"直接禁售**，另一层是**"平台未开放的香薰香道类商品"一律禁售**。

### 2.5 判读

**藏香在微信小店，最可能被归入"平台未开放的香薰香道类商品" → 不可上架。**
如果硬按「沉香/檀香 燃香」报类目，会同时踩 4.1.4(10) 混合香条款。

> ⚠️ 这是一条**推断**，依据是规则原文的类目表和禁售条款，不是平台给我的答复。
> **唯一能把它变成结论的办法**：在微信小店后台提交类目申请（**不交保证金也能提交**），
> 看审核结果。**在拿到结果前，不要交任何保证金。**

### 2.6 三条收银台路线对比

| 路线 | 可行性 | 平台费 | 代价 | 结论 |
|---|---|---|---|---|
| **A. 微信小店** | 🔴 类目大概率不过 | 技术服务费 + 支付费（官方表格需登录，**本次未能核实具体数字**） | 保证金 + 类目审核 2-3 工作日 | **不建议先投入**，先报类目试 |
| **B. 小程序自建 + 微信支付（JSAPI）** | 🟡 大概率可行，需实测 | 主要是支付手续费（费率**以后台为准**，业内常见 0.6%，**非官方原文，标注为待核实**） | 需办**微信支付商户号**（个体工商户可申请）；需服务端下单 + 回调；商品页自己做 | **推荐**：不受微信小店类目规则约束，且 `server/` 已有服务端骨架可扩展 |

我上一轮让页面**复制链接**到剪贴板。这个做法本身不算假功能（点了有反馈），但**体验很差**（用户要自己粘贴）。

→ 已从方案里剔除。等收银台路线定了再实现跳转，**不拿未核实的 API 写进代码**。

## 3. 算账：这才是最硬的一关

算式来自 `scripts/incense-pricing.js`（公开可复算），平台费率按脚本默认 **1% + 0.6%**（以后台为准）。

### 3.1 单捆零售（¥15 / 成本 ¥13）

| 运费谁出 | 单件毛利 | 毛利率 | 100 捆总毛利 |
|---|---|---|---|
| 买家出（我们不承担） | **+¥1.76** | 11.7% | +¥176 |
| 我们出 ¥6 | **−¥4.24** | −28.3% | −¥424 |
| 我们出 ¥8 | **−¥6.24** | −41.6% | −¥624 |
| 我们出 ¥12 | −¥10.24 | −68.3% | −¥1,024 |

**读法**：¥1.76 的毛利，**连一次 6 块钱的快递都扛不住**。包邮即亏，没有第二种解释。

复算命令：
```bash
node scripts/incense-pricing.js --cost=13 --price=15 --moq=100 --ship=8
```

### 3.2 多捆装（提高客单价，摊掉运费）

| 一单买几捆 | 客单价 | 我们出 ¥8 运费后的单件毛利 | 毛利率 |
|---|---|---|---|
| 1 捆 | ¥15 | −¥6.24 | −41.6% |
| 5 捆 | ¥75 | **+¥0.80** | 1.1% |
| 10 捆 | ¥150 | **+¥9.60** | 6.4% |

**读法**：**10 捆一单、客单价 ¥150、包邮，毛利率才 6.4%。** 这还是没扣退货、没扣开办费、没扣包装。

### 3.3 要实现 30% 毛利，售价得多少

成本 ¥13 + 包邮 ¥8 + 平台费 1.6% → 售价需 **≈ ¥30.7/捆**（现价 ¥15 的 2 倍）。

> 这是**算术结果，不是我的定价建议**。要不要卖 ¥30 由你定 —— 但注意 §4.1 的比价问题。

### 3.4 比价风险（用户 D131 里我已提过，这里再量化一次）

¥15 / 10 根 = **¥1.5 一根**。市场上机制线香常见 ¥0.5 一根上下（100 支盒装常见 ¥54）。
→ **我们的单价是常见价的约 3 倍**，靠"质量和产地"支撑，不靠价格。

**这条不解决就等于没解决流量**：没有品牌与内容背书，3 倍价在纯比价场景里卖不动。

### 4.1 需要你做的三件事（只有你能做）

1. **拍包装**：厂名、厂址、执行标准号、生产日期、净含量 —— 这五行决定 `origin` 和 `standard` 能不能留。
2. **拍一支香的近照**：看有没有竹签（决定 `form` 写"线香"还是"签香"）。
3. **发顺丰/中通/圆通的月结报价**（至少 3 家，报"首重 1kg 到全国"）。这一个数字决定这门生意成不成立。

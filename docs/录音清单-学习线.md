# 学习线录音清单

> 由 `node scripts/gen_recording_list.js` 从当前关卡内容生成 · 对应 `data/learn-audio.js`
> 待录 **206 条**

## 这份清单解决什么

学习线共 150 关、每关 14~46 张牌，但**去掉跨关重复后只有 236 种不同牌面**；
其中 **L1 的 30 个辅音本来就有真人录音**（`letter_01`…），配对成功即朗读 ✓。
**剩下 206 种在整条学习线里听不到声音** —— 这一批就是唯一还静默的部分。

> 口径：**没音源就静默，不假装出声、不拿别的音顶**（两端一致）。

## 怎么用（三步，代码侧一行都不用改）

1. 按下面的「音频 id」命名录好的文件，放进 `audio/voice/`（`.mp3` 或 `.wav` 都认）
   例：`audio/voice/learn_001.mp3`
2. 跑 `python scripts/gen_voice_index.py` 刷新 `data/voices.js`
3. 跑 `node scripts/validate.js` —— 「录音索引覆盖」门禁会复核；绿了即生效

两端的 `tib2Id()` 会按**藏文文本**自动接上新录音。
（学习关的牌面 id 是合成的 `lrn_{lv}_{st}_{i}`，同一句在不同关里 id 不同，所以录音只能按文本索引。）

## 建议批次（按教学顺序，越前越先教）

| 批次 | 级别 | 内容 | 条数 | 说明 |
|---|---|---|---|---|
| 第 1 批 | 2、3 | L2 元音符号 / L3 后加字 | 26 | 最划算 —— 26 条就能让「元音 / 后加字」整级出声 |
| 第 2 批 | 4、5、6、7 | L4 再后加字 / L5 前加字 / L6 上加字 / L7 下加字 | 50 | 四层附加字（再后加 / 前加 / 上加 / 下加） |

| 第 5 批 | 12、13 | L12 简单造句 / L13 复杂造句 | 5 | 造句（条数少，但需要成句朗读的节奏） |

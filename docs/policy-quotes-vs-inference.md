# 宗教商业化政策：原文要点 vs 我们的推论（Q12）

> 目的：**不让"推论"冒充"原文"**。本文把两类内容分开写：
> - **原文要点**：按条号复述；未逐字核对原文的，一律标注「待法务核对原文」，不得对外当逐字原文引用。
> - **我们的推论**：明确标注「推论，不是原文」，只作为产品决策依据。
>
> 依据文件：**国宗发〔2017〕88 号**（12 部门联合文件，2017-11-03）。

## 一、原文要点（复述，非逐字）

| 条号 | 要点（复述） | 状态 |
|---|---|---|
| 第 1 条 | 不得借宗教名义分红 / 提成 | 待法务核对原文 |
| 第 2 条 | 不得以佛教、道教名义进行商业宣传（不得冠以佛教、道教名称） | 待法务核对原文 |
| 第 5 条 | 不得将佛教、道教衍生商品 / 活动作为宗教用品、宗教活动经营 | 待法务核对原文 |
| 第 7 条 | 宗教活动场所兴办的经济实体独立核算、照章纳税 | 待法务核对原文 |

⚠️ 上表是**要点复述**，不是逐字原文。对外引用（提审、申诉、合同）前必须由法务核对原文。

## 二、我们的推论（推论，不是原文）

1. **机制藏香按 `GB/T 43430-2023` 进销 → 归为家居香品** —— 推论；实物线已随 D147 关闭，仅作历史留档。
2. **几何化纹样 ≠ 自动合规** —— 推论。是否合规看素材、用途、是否交易，不看"几何化"这一个特征。
3. **八吉祥 ≠ 一律违法** —— 推论。不能把"全部八吉祥一律违法"当成 88 号文原文结论。
4. **寺名只作产地 / 源流的客观陈述，不作营销背书** —— 推论。
5. **店铺 / 品牌 / 公司名不得冠以佛教道教名称** —— 推论（对应第 2 条）。

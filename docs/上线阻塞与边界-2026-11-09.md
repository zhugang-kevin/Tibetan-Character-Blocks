## 1. 本轮已解决（代码侧，可复跑）

### 1.1 播放看门狗不再「吃掉」玩家应得的奖励

**问题**：`show()` 成功但 `onClose` 永不来时，180s 看门狗把按钮放开，同时把这次观看判成
`timeout` 并不发奖 —— 玩家可能真的看完了，只是回调丢了。

**改法**：超时只放开按钮，同时开一个 **90s 补发窗口**；窗口内迟到的
`onClose({isEnded:true})` 仍补发一次，且只补一次。新一次观看 / `abort()` / `destroy()` /
`onError` 都会关掉窗口，避免陈旧回调凭空发奖。

| 判据 | 断言数 |
|---|---|
| `node scripts/test-ad-runtime.js` | **93 通过 / 0 失败** |
| `node scripts/test-ad-runtime-mutation.js` | **37 通过 / 0 失败**（含「超时不开窗」「窗口无上界」「去掉 `_late` 守卫」「页面不接补发」四条变异各自翻红） |

**如实留档（取舍，不是"已完美"）**：超过 270s（180s + 90s）才回来的 `onClose` 仍会作废。
理由是不能让几天前的回调在玩家早就不看的时候突然发奖；代价是极端情况下仍丢一次奖励。

### 1.2 隐私文档不再写死「当前不展示」

**问题**：原文档写「当前 6 个广告位 ID 为空、实际不展示」，而门禁**强制要求**这句话存在。
一旦填入 ID，文档立刻变成对用户的不实陈述，门禁却仍然绿 —— 典型的「自己给自己发假证明」。

**改法**：改为条件句「未配置时不展示；配置后仅展示微信官方广告组件」，
门禁改为**禁止**任何写死状态的断言（`STATE_CLAIM`），并保留「必须披露漏斗事件」。

| 文件 | 现在的写法 |
|---|---|
| `docs/privacy-policy-draft.md` §1 / §2.6 | 条件句 + 真实状态用命令核对 |
| `docs/privacy-mp-form.md` §1.6 | 以 `config/ads.js` 为准，填表前跑 readiness |

### 1.3 变异测试不再往仓库里写临时副本

**问题**：旧版把源码副本写进 `.workbuddy/tmp/ad-mut/`，跑完留 72 个文件；
2026-11-08 就是这些副本被 `validate.js` 当源码扫到 `wx.login`，导致全量 CI 假红。

**改法**：临时根改成 `os.tmpdir()/zangqu-ad-mut-<pid>`（系统回收），仓库零残留。
`validate.js` 的 `SKIP_DIRS` 仍然保留（纵深防御，有自证断言）。

已清理：`.workbuddy/tmp/ad-mut/`（72 文件）、`ad-mut2/`、`mutate-ads.js`、`mut.log`。
现在 `ls .workbuddy/tmp | grep -E "ad-mut|mutate"` 为空。

### 1.4 编译前结构门禁（缩小「静态全绿 ≠ 真机没问题」的黑箱）

新增 `scripts/test-wxml-lint.js`（**33 项**，其中 **9 项是自证**）：

## 2. 仍然阻塞的（外部，只能人工）

### 2.1 流量主与广告位

- 门槛：**累计 UV ≥ 500 且无违规**（查询日期 2026-11-07；以 mp 后台当日显示为准）。
- 路径：mp 后台 → 推广 → 流量主 → 广告位管理 → 新建。
- **一个 ID 只能用于一种类型**；`rewarded` 必须填 15/30 秒解锁时长。
- 填的时候只填 `banner` / `video` / `rewarded`；
  `interstitial` / `videoPatch` / `template` **运行时没有消费者**，填了会被
  `check-ads-config.js` 直接判红（填了不报错、不渲染、也不会有收入 = 最难发现的失败）。

### 2.2 真机验收

沙箱里**不能登录微信开发者工具**（会被 `reg.exe` 拦截），所以这一步没有任何自动化替代。
必须由你执行：

1. 开发者工具右上「上传」，填版本号与备注；
2. mp 后台设为体验版，加白名单；
3. 真机扫码，走一关，确认三件事：
   - 结算页广告位**首屏可见**（不用下滑）；
   - 激励入口只在广告**拉取成功**后才出现；
   - 看完一段后提示真的发出来（含超时后补发的那种）。

**为什么不能省**：WXML/WXSS 的编译错误常常只给 code 10、不给行号；
上面的静态门禁能挡掉四类结构错误，但样式最终渲染只能靠眼睛。

### 2.3 收益

**不估算**。竞价定价，官方不承诺单价；没跑满真实数据前任何数字都是编的。
当前广告位 ID 全空 → 页面零渲染 → 收入恒为 0（这是事实，不是保守估计）。

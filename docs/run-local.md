# 本地体验指南（5 分钟跑起来）

## 一、准备工作

1. 下载安装 **微信开发者工具**（稳定版）：
   https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   （Windows 选「Windows 64」；安装后首次启动需用微信扫码登录）

2. 项目位置（已在本机）：
   ```
   C:\Users\zhuga\WorkBuddy\2026-10-04-00-41-14\tibetan-match
   ```
   或用 `tibetan-match.zip` 解压到任意目录。

## 二、导入项目

1. 打开微信开发者工具 → 左侧选 **小程序** → 点 **+ 导入项目**
2. **目录**：选择 `...\tibetan-match`（选到含 `app.json` 的这一层）
3. **AppID**：点「**测试号**」（项目已配 `touristappid`，游客模式无需注册即可编译）
4. 后端服务：选「**不使用云服务**」（当前 MVP 全部本地存储）
5. 点 **导入** → 自动编译

> 若提示「游客模式无法使用某些能力」，忽略即可；本地模拟器全部功能可用。

## 三、怎么玩

| 步骤 | 操作 |
|---|---|
| 1 | 首页显示 10 个关卡，**第 1 关**可点，第 2-10 关为 🔒 |
| 2 | 首次进入会弹 **3 步新手引导**（消除 / 连击 / 文化卡），点「下一步」看完 |
| 3 | 点两张**相同**的牌 → 缩小淡出 + 铜铃声 → 底部弹文化卡 → 点「知道了」继续 |
| 4 | 点两张**不同**的牌 → 抖动弹回 + 轻声提示，不扣分（但**连击清零**） |
| 5 | 连续消除 ≥2 对 → 顶部弹「**连击 ×N**」，铃声升调，分数更高 |
| 6 | 牌面上带 **✦ 金色角标**的牌是特殊方块，消除得**双倍积分** |
| 7 | 消除全部卡片 → 自动进结算页：第 N 关完成 · 积分 · 连击 · 文化卡列表 |
| 8 | 第 1 关首次通关会盖「**拉萨**」文化护照印记（首页也会显示） |
| 9 | 结算页点「**下一关 →**」继续，或「返回首页」看进度 |
| 10 | 一路过到第 10 关 → 结算页出现「生成我的祝福卡」→ Canvas 生成可保存/分享的祝福卡 |

## 四、验收要点（对照 MVP 清单）

- 藏文 ཀ ཁ ག ང ཅ ཆ ཇ ཉ 显示正常（**不是方块/乱码**）
- 音效：点击「嗒」、消除铜铃、错误轻「噗」、通关铜铃+法号
- 关闭小程序再打开，进度保留（关卡解锁、印记、最高连击）
- 第 10 关通关后可生成祝福卡并保存到相册

## 五、常见问题

**Q1 藏文显示成方块？**
Windows / 安卓自带藏文字体，模拟器一般正常。若为方块（多见于部分 iOS）：
把 Google Fonts 的 `NotoSerifTibetan-Regular.ttf` 传到 HTTPS 服务器，填入
`app.js` 的 `TIBETAN_FONT_URL` 即可（未配置时已做静默跳过，不会报错）。

**Q2 没有藏文发音？**
`audio/voice/` 下需要 `letter_01.mp3 ~ letter_08.mp3` 真人录音（规格见该目录 README）。
未放置时静默跳过，不影响游戏。

**Q3 想重新体验新手引导 / 清空进度？**
开发者工具右上角 **清缓存 → 清除数据缓存**（或调试器 Storage 面板删 `progress`、`milestones`）。

**Q4 祝福卡生成失败？**
模拟器需较新基础库（项目已设 2.33.0）；真机微信需 8.0+。失败会提示「请再试一次」。

**Q5 声音没响？**
模拟器音效需在页面点击后触发（首次点击后即可）；检查系统音量与静音开关。

## 六、看埋点数据（Gate 1 测试）

调试器 → **Storage** 面板 → 查看 `milestones`：
key 为节点 id，值为**相对首次进入的秒数**，用于核对 15 分钟体验表：
`first_letter_seen / first_match / first_pronunciation / first_card / first_combo / first_special / first_stamp / next_level_click`

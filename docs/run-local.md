## 三、怎么玩（A / B 方案通用）

| 步骤 | 操作 |
|---|---|
| 1 | 首页显示 10 个关卡，**第 1 关**可点，第 2-10 关为 🔒 |
| 2 | 首次进入会弹 **3 步新手引导**（消除 / 连击 / 文化卡），点「下一步」看完 |
| 3 | 点两张**相同**的牌 → 缩小淡出 + 铜铃声 → 弹文化卡 → 点「知道了」继续 |
| 4 | 点两张**不同**的牌 → 抖动弹回 + 轻声提示，不扣分（但**连击清零**） |
| 5 | 连续消除 ≥2 对 → 弹「**连击 ×N**」，铃声升调，分数更高 |
| 6 | 牌面上带 **✦ 金色角标**的牌是特殊方块，消除得**双倍积分** |
| 7 | 消除全部卡片 → 自动进结算页：第 N 关完成 · 积分 · 连击 · 文化卡列表 |
| 8 | 第 1 关首次通关会盖「**拉萨**」文化护照印记（首页也会显示） |
| 9 | 结算页点「**下一关 →**」继续，或「返回首页」看进度 |
| 10 | 一路过到第 10 关 → 结算页出现「生成我的祝福卡」→ 生成可保存/分享的祝福卡 |

**提示**：A 方案的音效需要先点一下页面（浏览器要求用户手势后才允许出声）。

## 五、常见问题

**Q1 藏文显示成方块？**
Windows / 安卓自带藏文字体（`Microsoft Himalaya`），A、B 方案一般都能正常显示。
若为方块（多见于部分 iOS）：把 `NotoSerifTibetan-Regular.ttf` 传到 HTTPS 服务器，
填入 `app.js` 的 `TIBETAN_FONT_URL`（未配置时已做静默跳过，不会报错）。

**Q2 A 方案的进度存在哪？**
浏览器 localStorage 的 `zangzi_progress` 键。首页底部有「清空进度，重新开始」。
注意：与小程序版的进度**互不相通**（各自独立存储）。

**Q3 没有藏文发音？**
`audio/voice/` 下需要 `letter_01.mp3 ~ letter_08.mp3` 真人录音（规格见该目录 README）。
未放置时静默跳过，不影响游戏。

**Q4 想重新体验新手引导 / 清空进度？**
B 方案：开发者工具右上角 **清缓存 → 清除数据缓存**（或 Storage 面板删 `progress`、`milestones`）。
A 方案：点首页底部「清空进度，重新开始」。

**Q5 祝福卡生成失败？**
B 方案模拟器需较新基础库（项目已设 2.33.0）；真机微信需 8.0+。失败会提示「请再试一次」。
A 方案生成后可点「保存到本地（PNG）」直接下载。

**Q6 声音没响？**
需在页面点击后触发（首次点击后即可）；检查系统音量与静音开关。

## 六、看埋点数据（Gate 1 测试）

# 科技公司主体：这个游戏能靠什么赚钱（2026-10-21）

> 前提：主体 = **科技有限公司**（企业），服务器与域名均为**国内**。
> 每条只写**官方原文能支撑的**；官方没给的写「以后台为准」，我不编。

---

## 0. 一句话

**科技公司主体下，能确定赚到钱的路只有三条：虚拟支付（打赏/礼物/解锁）、广告、实物电商。**
其中**唯一现在就能开通、且代码已经写好的，是虚拟支付。**

而被我上一轮推错的那条——**「教育」类目走不通**：官方要求《民办学校办学许可证》，
科技公司没有，这条作废。

---

## 1. 三条路：科技公司逐条对照

| | 变现方式 | 科技公司能不能做 | 官方条件（原文） | 现在缺什么 |
|---|---|---|---|---|
| **A** | **虚拟支付**（打赏 / 虚拟礼物 / 解锁功能 / 付费功能） | ✅ **能，最直接** | 「已认证小程序」「企业 / 事业单位 / **个体工商户**」「主体信息完备」——官方只列这三条 | 微信认证（300 元）+ 后台点开通（1-7 工作日审核 + 签约） |
| **B** | **广告**（流量主：Banner / 插屏 / 激励视频 / 视频 / 前贴 / 原生模板 / 封面 / 支付订单详情页） | ✅ 能 | 「小程序**累计独立访客（UV）1000 以上**，且无违规记录」 | **1000 个真人用过**（现在 0） |
| **C** | **实物电商**（藏香） | ⚠️ 能卖，但**类目卡住** | 微信小店「香道用品」只开放 沉香/檀香 单方燃香，且禁「混合香」以燃香名义出售（D133） | 一条收银台通路（小店类目 或 自建微信支付） |

### A. 虚拟支付 —— 为什么说它是"现在就能做"的那条

**官方定义（《虚拟支付业务运营指南》原文）**：

> 「开发者在小程序内提供的虚拟商品（包括虚拟货币、**解锁功能**、订阅内容、**付费功能**、**打赏**、
> **购买虚拟礼物**等），购买和支付均需接入小程序虚拟支付；**不得引导至 app、公众号、h5、个人号、网站完成支付**。」

我们已有的四个道具 —— 酥油灯 ¥1 / 哈达 ¥3 / 祝福卡 ¥6 / 藏文名字 ¥9.9 —— **全部落在这一条里**。
`utils/payment.js` + `server/` 已经按官方虚拟支付（米大师）实现，**方向本来就是对的，不用重做**。

**科技公司 = 企业主体**，正好是官方列的第一类主体。开通不需要版号、不需要软著、
不需要任何行业许可证 —— **这一页官方全文没有出现"类目""备案""版号""软著"任何一个词**。

**费率（只写官方给了的）**：
- 官方对"企业 / 个体户"只写「按一定费率收取技术服务费」「扣除 Apple 佣金」，**没给数字**
- 官方对"个人主体"公示：**Android 等 1% 腾讯技术服务费 / iOS 12% Apple 佣金**
- → 你的企业主体费率**以开通页签署的协议与后台显示为准**，我不替你填数字

**一条必须知道的雷**：
> 「若小程序**仅包含**以上虚拟类目，平台将**关闭该小程序在安卓及其余非 iOS 系统的普通微信支付能力**」
> 「同时包含虚拟商品和实物商品（如在线课程赠送教材）将被认定为虚拟支付，**建议拆分为两笔交易分别处理**」

→ 卖虚拟礼物和卖藏香**必须分成两笔交易**，不能一单混收。

### B. 广告 —— 不是"选不选"的问题，是"先有 1000 人"

- 官方门槛只有一句：**UV ≥ 1000 且无违规**。没有主体限制，科技公司当然可以。
- 普通小程序**可以接激励视频**（官方文档在 `miniprogram/.../rewarded-video-ad.html`，
  2019 年起视频广告与前贴已对**非游戏类小程序**全量开放）。
- **我不估算收益**：单价由竞价决定，官方不承诺任何数字。UV 1000 是"能开通"的门槛，
  不是"能赚钱"的门槛 —— 真实收入取决于留存和人均看广告次数。
- 结论：这是**第二顺位**，不是第一。**没有用户，广告收入是 0。**

### C. 实物（藏香）—— 能卖，但要先解决通路

- 微信小店：企业店可开，但「香道用品」类目只开放 **沉香 / 檀香单方燃香**，
  且 **4.1.4(10) 禁「混合香」以燃香名义出售** → 藏香（复合香）没有明确可挂的开放类目（详见 D133）。
- 自建路径：科技公司可申请**微信支付商户号**（企业，对公账户），自己做商品页 + 下单 + 回调。
  `server/` 已有服务端骨架，扩一个实物订单接口即可。
- 🔴 **一个容易漏的硬条件**：营业执照**经营范围**要覆盖所售商品。卖实物通常需要含
  「互联网销售」「日用品销售」「工艺美术品销售」之类。**如果你的科技公司经营范围只有技术开发/技术服务，
  类目审核会卡**（微信小店入驻要求"经营范围需覆盖所售商品类目"）。这条要先改执照，7-15 个工作日。

## 2. 类目：科技公司到底能选哪些（这张表决定上面能不能开）

| 类目 | 官方资质要求 | 科技公司 |
|---|---|---|
| 教育服务-**在线视频课程** | 《民办学校办学许可证》/《非学科类校外培训机构培训许可证》/ 教育部门批文 等（5 选 1） | ❌ 没有 → **我上一轮的建议作废** |
| 教育服务-**其他在线视频课程** | 企业主体：①《营业执照》②《非经营性互联网信息服务备案核准》或《增值电信业务经营许可证》（含互联网信息服务业务）③《小程序开发者承诺函》 | ✅ 可满足（面向**非教育行业**的兴趣才艺类课程） |
| 教育服务-**非学科类培训机构** | 《民办学校办学许可证》/《非学科类校外培训机构培训许可证》/《文化艺术类校外培训机构审核意见书》/ 全国校外教育培训监管平台备案（4 选 1） | ❌ 没有 |
| **游戏**（小游戏） | IAP 需**版号 + 软著**；IAA 只需自我声明 + 自审报告 | ⚠️ 纯广告行；**要内购就必须版号** |
| 商家自营 / 电商 | 《营业执照》经营范围覆盖 | ⚠️ 看执照范围（见 §1.C） |

**结论：科技公司真正能站住的是「其他在线视频课程」这一条（非教育行业的兴趣才艺类），
或者干脆不选教育系、按实际功能选类目。** 但无论选哪个，**「类目必须与页面核心内容一致」这条是硬规则**——
我们的页面核心内容是「150 课藏文课程 + 配对练习」，必须让审核一眼看出**这是课程，不是纯游戏**。

## 3. 直接回答你的问题：靠什么赚钱

**按"能收钱的先后顺序"排：**

| 顺位 | 路径 | 收谁的钱 | 客单价 | 前置 | 时间 |
|---|---|---|---|---|---|
| **1** | **虚拟礼物 / 打赏（虚拟支付）** | 用户给朋友送哈达、酥油灯、祝福卡、藏文名字 | ¥1 / ¥3 / ¥6 / ¥9.9 | 认证 + 开通虚拟支付 | 认证 1-5 工作日；开通审核 1-7 工作日 |
| **2** | **广告（流量主）** | 广告主 | 按曝光/点击，官方不定价 | UV ≥ 1000 | 取决于获客速度 |
| **3** | **实物藏香** | 买香的人 | ¥15/捆（毛利 ¥1.76） | 收银台 + 执照经营范围 | 见 D133，类目是硬卡点 |

**如果只做一件事：做虚拟支付。** 它不需要版号、不需要许可证、代码已就绪、主体条件已满足，
是这三条里**唯一一条"条件全部在手，只差去开通"**的。

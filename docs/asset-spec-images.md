# 图片资产规格书（真实图片生成指令 · 交付版）

> **用途**：本文件是「藏字方块」全部图片资产的**生产指令**。拿着它可以直接在任意 AI 绘图工具
> （Midjourney / 即梦 / 文心一格 / SD / 混元……）批量生成，再按「命名 + 尺寸 + 大小上限」放回仓库即可上线。
>
> **本文件不是**：策划文档（项目纪律：不新增策划文档）。它是**生产规格**——每一条都能被校验、被接入。
> 状态：2026-10-07 初版 · 与 `scripts/prepare-assets.py`（自动加工脚本）配套使用。

---

## 〇、先读这 6 条铁律（违反任何一条都会被打回）

1. **绝对不放文字**。任何一张图里都不许出现文字、字母、印章、水印、二维码。文字一律由程序叠加。
2. **禁用色**：纯黑（#000000）、荧光色、高饱和纯色。**必用色板**见 §一。
3. **主体占比 ≥ 75%**，缩到 40px 仍能一眼辨认（在生成工具里自行缩图检查）；细密纹理只在 512px 以上源图保留。
4. **宗教红线**（D25）：**佛像/菩萨像/经文/法器（金刚杵、法铃）/佛塔/酥油灯/风马旗/莲花/经幡
   不得出现在"游戏牌面元素"里**；八吉祥等纹样仅可用于**装饰位**（背景纹样、揭图，见各条目注明）。
5. **背景要求分两类**，看条目里的「背景」字段：
   - `透明` → 输出 PNG/WebP **带 Alpha 通道**，主体之外完全透明；
   - `不透明` → 输出 JPG/WebP（无 Alpha），整幅铺满。
6. **交付原始大图**（1024px 以上、无损或高质量），**不要自己压缩**——尺寸/体积由
   `scripts/prepare-assets.py` 统一加工，避免各图风格尺寸参差。

- **C1 全屏底**：竖构图，自上而下 夜色深蓝 `#0B1E36` → 暗红 `#6B1A1A` 的柔和渐变，

  顶部最亮、往下渐隐到全透明。**禁止月亮画成大圆盘遮字**。
- **C3 剪影层**：透明底，底边一排**雪山连峰 + 布达拉宫式建筑剪影**（实心深色 `#10203A` 90% 不透明），
  底部对齐，顶部起伏自然；轮廓要"远山感"（不要卡通锯齿）。提示词：`底部一排雪山与藏式宫殿建筑剪影，实心深色，顶部起伏自然，透明背景`
- **C4 纹样砖（⚠️ 有机械要求）**：2:1（128×64），**上下左右无缝平铺**（tileable），
  纹样主题 = 八宝 + 卷草藤蔓的简化线条，单色（藏金 `#8A6A12`），线条粗细 1–2px，
  **图案距边缘 6px 内不可有笔画**（保证平铺时不"切"图案）。生成后可交给我做无缝校正。
- **C5 颗粒噪点**：透明底、极淡的纸纤维颗粒（灰白点，最大不透明度 6%），平铺无 seams。

## 七、交付与接入流程（照做，全程 10 分钟）


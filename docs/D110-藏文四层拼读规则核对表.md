# D110 · 藏文四层拼读规则核对表（上加字 / 下加字 / 前加字 / 后加字）

> 目标口径：项目此前只有**基字**一层读音。四层附加字**完全没有读音**。
> 本表把四层的**规则 + 合法组合 + 拉萨音**逐条列出，**每条带出处**，
> 并由 `scripts/audit_affix_reading.py`（判据独立写死）+ `scripts/validate.js` §59.23 机械核对。
> 声调记号：`á` = 高平 55（清声母字），`à` = 低升 12（源自浊声母字）。

---

## 0. 这次顺带挖出的真 bug（不是理论推演）

`data/learning.js` 的 L5 / L6 / L7 原先写的是「附加字池 × 基字池」的**笛卡尔积**，
而藏文里附加字能跟哪些基字结合是**有穷举表**的。实际枚举（跑 `utils/learning.js`）的结果：

| 级别 | 层 | 不同音节 | 其中藏文不成立 | 具体 |
|---|---|---|---|---|
| L5 | 前加字 | 14 | **7** | གཁ བང མཅ གཇ དཉ བཕ མབ |
| L6 | 上加字 | 14 | **7** | རཁ རཅ ལཆ སཇ སཐ ལན རཕ |
| L7 | 下加字 | 14 | **10** | ཁླ ངྱ ཅྲ ཆླ ཇྭ ཉྱ ཐླ དྭ ནྱ ཕླ |

**游戏在教藏文里根本不存在的字。** 已改为直接用穷举好的合法组合池（D110）。

## 1. 上加字（3 个：ར ལ ས）

**集合**：上加字只能是 ར / ལ / ས —— 维基百科「藏文」·书写方法。
**连接顺序**：前加字 → 上加字 → 基字 → 下加字 —— 同上。

| 上加字 | 可接基字数 | 基字穷举 | 出处 |
|---|---|---|---|
| ར | 12 | ཀ ག ང ཇ ཉ ཏ ད ན བ མ ཙ ཛ | 美篇《入学藏文基础上加字》ར་མགོ་བཅུ་གཉིས |
| ལ | 10 | ཀ ག ང ཅ ཇ ཏ ད པ བ ཧ | 同上 ལ་མགོ་བཅུ |
| ས | 11 | ཀ ག ང ཉ ཏ ད ན པ བ མ ཙ | 同上 ས་མགོ་བཅུ་གཅིག |

**音变规则**（中文百科 / 360 百科「藏文上加字」；规则 3 另由 Perekhvalskaya《Lhasa Tibetan》2025 讲义独立印证）

| 规则 | 条件 | 效果 | 例 |
|---|---|---|---|
| SP1 | 加在高平不送气音 ཀ ཅ ཏ པ ཙ 上 | 上加字**不发音**，读音 = 基字本音 | རྐ ལྐ སྐ = gá |
| SP2 | 加在低升送气音 ག ཇ ད བ ཛ 上 | 声母**送气 → 不送气**并升高平调；上加字 ལ 另带对应部位**鼻冠音** | རྒ = gá、རྗ = já、རྡ = dá、རྦ = bá、རྫ = zá |
| SP3 | 加在鼻音 ང ཉ ན མ 上 | 音节**低升 → 高平** | རྔ = ngá、རྙ = nyá、རྣ = ná、རྨ = má |
| SP4 | ལ 加在 ཧ 上 | 拼出**边擦音 lh** | ལྷ = lhā |

> ⚠️ 注意一处易错点：**རྐ 与 རྒ 同音**（都读 gá）—— SP1 是不发音、SP2 是送气变不送气，
> 两条路最后落到同一个音上。这不是笔误，是权威示例的直接结果。

## 2. 下加字（4 个：ྱ ྲ ླ ྭ）

| 下加字 | 名称 | 可接基字数 | 基字穷举 | 音变 | 出处 |
|---|---|---|---|---|---|
| ྱ | ཡ་བཏགས | 7 | ཀ ཁ ག པ ཕ བ མ | 腭化：k/kʰ→c/cʰ；p/pʰ→tɕ/tɕʰ | 搜狗/百度百科「藏文下加字」 |
| ྲ | ར་བཏགས | 12 | ཀ ཁ ག ཏ ཐ ད པ ཕ བ ཧ ས མ | 卷舌化：→ʈʈʂ / ʈʂʰ；ཧྲ→ʂ | 同上 |
| ླ | ལ་བཏགས | 4 | ཀ ག བ ཟ | 边音化 / 鼻音化 → l（高调）；ཟླ→ntʰ | 同上 |
| ྭ | ཝ་ཟུར | 3（见下） | ཀ ཁ ག | 圆唇，**对现代拉萨音发音已无影响** | 同上 + 百度百科「藏语」拉萨音对照表 |

**读音（拉萨音拼音）**

| 组合 | 读音 | 组合 | 读音 | 组合 | 读音 |
|---|---|---|---|---|---|
| ཀྱ | gyā | ཁྱ | kyā | གྱ | kyà |
| པྱ | jiā | ཕྱ | qiā | བྱ | qià |
| མྱ | nyà | | | | |
| ཀྲ ཏྲ པྲ | zhā | ཁྲ ཐྲ ཕྲ | chā | གྲ དྲ བྲ | chà |
| ཧྲ | shā | སྲ | sà（与 ས 同） | མྲ | mà（与 མ 同） |
| ཀླ གླ བླ | lā | ཟླ | ndà | | |
| ཀྭ | gá | ཁྭ | ká | གྭ | kà |

**两条容易搞混的**

1. **སླ / རླ 不是下加字**——权威原文：「སླ、རླ 则相当于 ལ 加上加字 ར、ས」。
   它们字形和下加字 ླ 一样，但结构是「上加字 + 基字 ལ」，归**上加字层**。本表不收。
2. **ྭ 的穷举表权威源没给全**，只收有直接出处的 ཀྭ ཁྭ གྭ 三条，**不臆造其余组合**。

## 3. 前加字（5 个：ག ད བ མ འ）

**各自可接基字的穷举**（百度百科「藏文前加字」规则 1–5）

| 前加字 | 可接基字数 | 基字穷举 |
|---|---|---|
| ག | 11 | ཅ ཙ ཉ ཡ ཏ ད ན ཤ ས ཞ ཟ |
| ད | 6 | ཀ ག ང པ བ མ |
| བ | 10 | ཀ ག ཅ ཙ ཏ ད ཤ ས ཞ ཟ |
| མ | 11 | ཁ ག ང ཆ ཇ ཉ ཐ ད ན ཚ ཛ |
| འ | 10 | ཁ ག ཆ ཇ ཐ ད ཕ བ ཚ ཛ |

**读音规则**

| 规则 | 条件 | 效果 | 出处 |
|---|---|---|---|
| PF1 | 加在 ཀ ཁ ཅ ཆ ཏ ཐ པ ཕ ཙ ཚ ཤ ས ཞ ཟ 前（14 个） | 前加字**不发音，也不影响**基字发音 | 百度「藏文前加字」规则 6 |
| PF2 | ག ད བ + ག ཇ ད བ ཛ | 前加字不发音，但使基字**送气 → 不送气** | 规则 7 + 百度「藏语」 |
| PF3 | མ འ + ག ཇ ད བ ཛ | 增加**对应部位的鼻冠音** | 规则 11 + 百度「藏语」 |
| PF4 | ག ད བ + ང ཉ ན མ ཡ | 低升调的鼻音与半元音 **变高平调** | 规则 12–13 + 百度「藏语」 |
| PF5 | ད + བ | བ 变半元音或零声母：དབའ=wá、དབྱ=yá、དབྲ=rá | 规则 8–10 + 百度「藏语」 |

## 4. 后加字（10 个）+ 再后加字（2 个）

**第一后加字 10 个**：ག ང ད ན བ མ འ ར ལ ས —— 维基百科「藏文」
**第二后加字 2 个**：ས（接在 ག ང བ མ 后 → གས ངས བས མས）、ད（接在 ན ར ལ 后 → ནད རད ལད）—— 百度百科「藏语」规则 9–10

**读音规则**（百度百科「藏语」·后加字 10 条；与有道/百度百科「藏文后加字」8 条互为印证）

| 规则 | 后加字 | 效果 |
|---|---|---|
| SF1 | ར | 延长元音（a→aː / o→oː / u→uː / e→eː / i→iː） |
| SF2 | ལ | 改变元音（a→ɛ / o→ø / u→y / e→eː / i→iː），对声调无影响 |
| SF3 | འ | འི འུ འེ འོ 与前面元音构成长元音或复元音；འ 本身是**占位符** |
| SF4 | ད | 使元音鼻化（a→ɛ̃ / o→ø̃ / u→ỹ / e→ẽ / i→ĩ） |
| SF5 | ང | 形成韵尾 ŋ |
| SF6 | མ | 形成韵尾 m |
| SF7 | ག | 形成韵尾 q + 变调（高平 f→h、低升 v→w）；本身一般不发音 |
| SF8 | བ | 形成韵尾 p + 变调；后音节词尾 བ 与前音节合并成长元音/复元音 |
| SF9 | ས | 形成韵尾 ʔ + 变调 |
| SF10 | ད | 形成韵尾 ʔ + 变调 |

**第二重保险**（维基百科「标准藏语」，可与上表互校）
- 以 ས ད ན ལ 为第一后加字时元音音变：a→ɛ、o→ø、u→y；ས ད 不发音；ན 与元音合成鼻化元音。
- 以 -ག -གས -བ -བས -ད -ས -ངས -མས 为后加字时：原高平调变降调，原低平调变低升降调 132。

## 6. 诚实边界（不知道的就说不知道）

1. **ྭ 的完整组合表**在所查权威源中没有穷举，只收 ཀྭ ཁྭ གྭ 三条，其余**不臆造**。
2. **上加字示例的声调符号**在原始网页里有 OCR 噪声（རྐ 一处写 gā、རྒ 写 gá）。
   本表按规则推导统一取**高平**，并保留原示例字样于上表。
3. **འ 后加字**在现代拉萨音中不单发音，通常与 ི ུ ེ ོ 组成复合元音；
   学习体系 L3 里出现的 ཆའ 一类**裸 འ 收尾**音节，未查到权威源明确判其为非法，
   故**保留不动**，但也不把它当普通韵尾来教（读音规则 SF3 已标注它是占位符）。
4. **读音是文本标注，不是音频**。四层的 TTS 音频尚未录制，
   受主包预算约束（D110 时点：1837KB / 上限 1846KB，余量 9KB），
   已按既有机制登记为待录项，不假装已有音频。

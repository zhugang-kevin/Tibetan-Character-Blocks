# 150 课 · 课型与复习调度（Q4 / D149）

> 目的：回答「150 课的课型（引入/复习/拼读/词汇）与复习按什么规则」，
> 并把它做成**可计算、可门禁**的规则：`scripts/lib/lesson-plan.js` + `scripts/test-lesson-plan.js`（15/0）。
>
> 🔴 边界：本规则**只定义"该复习什么"**，**不改任何关卡的盘面内容**（不改指纹、不动关卡）。
> 真正把复习内容替换进盘面属于改关卡，需单独批准 + `--update --reason`。

## 1. 课型（按级）

| 级别 | 课型 | 内容 | 依据 |
|---|---|---|---|
| L1 | **引入 intro** | 10 课 × 3 个新辅音 = **30 辅音** | `data/learning.js → CONSONANTS`（30） |
| L2–L10 | **拼读 phonics** | 元音 / 前后加字 / 叠字 / 音节 | `utils/learning.js → titlesFor` 的池 |
| L11–L15 | **词汇 vocab** | 真词 / 短句（含 3×3 大盘） | 同上（curated 词句池） |

课型是**按级派生**的纯函数：`kindOf(lv)`，不写死在任何关卡数据里。

## 2. 复习调度（间隔重复）

- **复习课**：每 5 课一个（`flatIndex % 5 === 0`）。150 课 → **30 个复习课**。
  例：L1-5、L1-10、L2-5 …… L15-10。
- **回看目标**：每课建议回看 **1 / 3 / 7 课前的同课型内容**（越界则跳过）。
  例：L1-5 → 回看 L1-4、L1-2（7 课越界）；L6-1（第 51 课）→ 回看 L5-10 / L5-8 / L5-4。
- **只往回看、不越界、同课型** —— 由门禁逐条校验，不允许"复习未来课"或"跨课型乱指"。

## 3. 覆盖约束（硬）

- L1 的 30 个辅音必须**不重不漏**：每个恰好出现 1 次。
- 门禁 `test-lesson-plan.js` 会逐字统计；变异测试（把某个辅音换成重复的）会**翻红**。

## 4. 为什么"复习"不直接改盘面

- 关卡内容由 `data/learning.js` + `utils/learning.js` 生成，受 `test-level-guard.js` **逐关指纹**保护。
- 把复习内容替换进盘面 = 改关卡 → 指纹变化 → 必须显式 `--update --reason` 并重跑 150 关全量。
- 因此本轮只落**规则与门禁**；盘面级复习作为独立变更（需批准）。

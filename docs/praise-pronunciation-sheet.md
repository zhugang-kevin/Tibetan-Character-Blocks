# 夸赞文库 · 藏文读音签确表（25 条 · 供语音专家校对）

> **用途**：`data/praise.js` 中 25 条藏文夸赞短语的**读音**签确表（与 `praise-native-review-sheet.md` 语义层配对）。
> **重要架构事实（先读）**：
> - 这 25 条藏文目前在游戏里**只作文字显示**（档位 ≥3 显示藏文大字），**游戏不会念出声**。
> - `audio/voice/praise_2..5` 是**中文**激励播报（"很好/非常好/你好厉害/你简直就是无敌"，Edge TTS 生成），**不是藏文读音**。
> - 因此本表是「读音校对」的**参考底稿**：供语音专家核对每条藏文的拉萨音是否正确（用于：① 确认文字读音无误；② 作为日后生成/校验藏文读音音频的基准）。
>
> **机器角色（去伪）**：Wylie 为**精确机械转写**（100% 由拼写得出，无歧义）；拉萨音一栏中，
> 标 **[Wik.]** = 取自 Wiktionary 拉萨音 IPA（权威可直接采信）；
> 标 **[规则·待专家]** = 机器按拉萨音规则推导的罗马字/近似 IPA，**连读、语调、送气细节需语音专家听读校正**。
> 机器**不代做听读签确**。
>
> **签确方式**：语音专家听读/拼读每条后，在「语音专家签确」栏打 ✓（与机器一致）或写出正确拉萨音。

## 机器去伪汇总（读音层）

- **Wylie 转写 25/25 精确**（机械得出，拼写→转写零歧义；拼写合法性已由 validate §32 机械保证）。
- **直接有权威拉萨音 IPA 锚点**（Wiktionary / Rangjung Yeshe）的词：ཡག་པོ / མིག / འདི / ཡིན / ལེགས་པོ / ཆེན་པོ / མཛེས / བཀྲ་ཤིས་བདེ་ལེགས / ཤིན་ཏུ / ཡང་དག་པ / ཕུན་སུམ་ཚོགས —— 这些词的单读音可信度高。
- **需语音专家重点听读**（机器仅能给规则推导、无权威 IPA 锚点，或含连读/送气细节）：རྣོ / མུ་མཐུད / ལག་རྩལ / བརྟན་པོ / ཧ་ཅང་ / ངོ་མཚར / དཔེ་མེད / གློག / འདྲ / ཕུལ་དུ་བྱུང་བ，以及**所有多音节组合词的连读语调**（机器无法断言短语层面的声调/停顿/同化）。
- **没有发现有拼写合法但读音会"读错意思"的硬伤**；读音层的唯一不确定来自"机器无真人听读能力"，故全部标「待专家校正」。

## 与语义层的关系

- 语义层（[`praise-native-review-sheet.md`](./praise-native-review-sheet.md)）：用户已于 2026-10-13 人工确认**翻译准确**（语境对接游戏时成立）。
- 本表（读音层）：待语音专家签确。**两层都签确后**，由**人工**将 `data/praise.js` 顶部 `pendingNativeReview: true` 翻为 `false` 并补 `native_reviewer` / `review_date`。机器不得代翻（防假绿）。

## 签确后可选动作（待你定）

1. **仅校对**：专家在表中打 ✓ / 修正，确认文字读音正确 —— 当前游戏「只显示不发音」也已足够（玩家看藏文、听中文播报）。
2. **生成藏文读音音频**：若要让游戏也**念出藏文夸赞**，可用现有天翼卫藏 TTS 栈（`scripts/gen_pronunciation.py`）为这 25 条生成藏文 MP3（多音节短语 TTS 可正常发声，孤立辅音发不出的问题不在此出现），再接入 `audio.speak()` 播放。生成后仍需语音专家**听审音频**而非只读表。
   - ⚠️ 预算提示：主包仅剩 ~1KB 余量，25 条藏文音频（≈24kbps×平均 1.5s ≈ 4.5KB/条 ≈ 110KB）**无法烤进主包**，需走分包/CDN 流式加载（与既有的 9 条缺音问题同一架构决策）。

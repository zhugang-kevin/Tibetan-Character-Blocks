## 1. 已知限制（看到这些**不要**报 bug）

| 现象 | 为什么 | 正确做法 |
|---|---|---|
| 入口写「练习模式 · 10 课」，不是「闯关/纯游戏」 | 小程序不是小游戏，教育/课程类目对"游戏"措辞敏感（`validate` 红线） | 这是命名决策，不是 bug |
| 学藏文牌面全是**同一种墨色** | 颜色不再编码字母，逼玩家认字（D152 双轨） | 这是学习设计；觉得难请记录，不要要求"加回颜色" |
| 最后一对后要等约 2.2–2.6 秒才进结算 | 等语音念完，避免半句藏语 | 界面上有「**跳过等待 →**」；若点了不跳，才是 bug |
| 学习面板看不到「全部解锁（验收用）」 | 只对 `?all=1` / `?verify=1` 显示 | 玩家界面不出现是预期 |
| 首页没有"第 11 关" | 练习模式只有 10 课；150 课是另一条线 | 走「学藏文 · 150 课」 |
| 体验版主流程里没有识认测验页 | Q1 单独放在 `preview/q1.html`（网页版）和小程序 `pages/recognition` | 不要在 `play.html` 里找；Q1 用单独页面 |
| 无音频设备时 `AudioContext` 报错 | 无头/无声卡环境 | 只在真机上判断音频问题 |

## 4. 选测路径（P1）

### 音频（真机；外放与耳机各一次）

| 场景 | 操作 | 期望 |
|---|---|---|
| 元素发音 | 配对成功一次 | 约 300ms 后读该字母；不被祝福语盖掉 |
| 场景祝福 | 连击 4+ | 只播一次；9 秒内不重复 |
| 通关 | 打完一关 | 念完祝福再进结算；不想等可点「跳过等待」 |
| 错配 | 点两张不配对的牌 | 只有错配音效，不播藏语祝福 |
| BGM duck | 语音播放时 | BGM 明显压低，语音结束后恢复 |
| 开关 | 关闭音乐/音效 | 对应声音消失；重进仍保持 |

- 中断：结算等待中切后台再回来；杀掉小程序重进（进度是否保留）。
- 分享/挑战：分享卡进入、接受挑战（若未接，忽略）。
- 150 课抽样：L2-10、L5-5、L8-1、L10-10、L15-10（各 1 次，确认不卡死）。

## 6. 严重度定义

- **P0**：进不去、卡死、白屏、进度丢失、结算不出现、音频持续爆音。
- **P1**：主流程某一步走不通（如「下一课」无效、150 课某关进不去）。
- **P2**：显示/文案/对齐/错别字（截图 + 设备）。
- **P3**：体验建议（不阻塞）。

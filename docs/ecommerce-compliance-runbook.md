# 电商合规与履约全流程（2026-10-22）

> 面向的现实：卖**藏文化成品配饰**（非宗教用品、非食品、非化妆品）。
> 每条都写"要做什么 / 系统落在哪 / 怎么判它做到了"。**拿不准的地方我标了"待核实"，不编。**

---

## 零、先认清三件事

1. **国家管控的不是"卖小饰品"，是"卖东西这件事本身"**：亮照、开票、质量、售后、物流可追溯。
2. **平台的管控比国家更细**：类目、发货时效、发货信息回传、投诉率，任何一项不达标就限流或下架。
3. **我们的短板不在货，在资质与流程**：营业执照经营范围没有"销售"，这条不解决，后面全空。

## 二、七步流程（每步含规范动作 + 系统落点）

### 步骤 1｜备货

| 规范动作 | 系统落点 |
|---|---|
| 只进**一款**：迷你擦擦吊坠 ×3 题材 ×10 个 ≈ **1,000 元** | 库存表（后台手工维护即可，先不做系统） |
| 每款拍照：整体 / 细节 / 尺寸参照（放硬币） | 商品图 |
| 向供货方索要：**营业执照复印件、增值税发票、材质说明** | 存档到 `docs/supplier/`（不入 git） |
| 到货自检：掉色、毛刺、绳结牢固、有无异味 | 抽检记录 |

**判据**：30 个货到手，能拍出 9 张可用图，且三家供货材料齐全。

---

### 步骤 2｜上架

| 规范动作 | 系统落点 |
|---|---|
| 类目选**饰品/工艺美术品**（不是宗教用品） | 后台服务类目 |
| 标题按公式：`迷你唐卡擦擦吊坠 · 绿度母` | 商品库 |
| 详情页必含：材质、尺寸、**成品含绳**、产地、售后规则 | 商品详情 |
| **不写**：开光/加持/供奉/保佑/消灾/转运/招财、纯金纯银、矿物颜料、非遗 | 门禁 `test-religion-compliance.js` 守 |
| 价格 49/52/55（三题材） | 服务端价格表，**前端不写死** |
| 库存填**真实数字**，0 时按钮显示"缺货" | 商品状态 |

**判据**：商品页把"是什么、多大、什么材质、能不能退"四件事说清，且没有一句功效或宗教表述。

---

### 步骤 3｜收款

| 规范动作 | 系统落点 |
|---|---|
| 用**普通微信支付**（实物），不要用虚拟支付 | 商户号 + 后端下单 |
| 金额**只在服务端计算**，前端只传商品 id 与数量 | `server/` 下单接口 |
| 订单落库：订单号、商品、金额、openid、状态 | `orders` 表 |
| 支付回调**验签**，幂等（同一订单只入账一次） | 回调接口 |
| 费率 0.6%，结算 T+1 到对公账户 | 微信支付后台 |

**判据**：付一笔 1 分钱（测试价）能走通全链路，订单表里有记录，金额与前端显示一致。

---

### 步骤 4｜发货（平台最看重的一步）

| 规范动作 | 系统落点 |
|---|---|
| **48 小时内出单号**（平台考核项） | 订单后台填单号 |
| 用**微信「发货信息管理」**回传物流（2023 年起要求） | 后台发货操作 / 接口回传 |
| 包装：气泡袋 + 硬卡纸 + 绒袋；**易碎件加护角** | 手工 |
| 每单附一张小卡：退换规则 + 客服入口二维码 | 印刷 |

**判据**：任意订单，付款后 48 小时内状态从"待发货"变"已发货"，且用户能在订单页看到单号。

> 🔴 **红线**：超过 48 小时不发货，平台会判"发货超时"，累计会限制流量甚至下架。

---

### 步骤 5｜物流跟单

| 规范动作 | 系统落点 |
|---|---|
| 用户能在订单页点开**查物流** | 接快递查询（微信物流助手 / 快递100） |
| 每天扫一次"异常件"：滞留超 3 天、退回、丢件 | 人工 + 后台标记 |
| 异常件**主动**联系用户，不让用户追 | 客服 |

**判据**：任意一单，用户不用问客服就能看到物流轨迹。

---

### 步骤 6｜签收

| 规范动作 | 系统落点 |
|---|---|
| 签收后 24 小时内发一条"收到还满意吗"+ 客服入口 | 订阅消息（需用户授权） |
| 签收 7 天内可申请售后 | 售后入口 |
| 好评引导：**不返现、不诱导**（返现好评违反平台规则） | —— |

**判据**：签收后用户能在小程序里找到"申请退换"的入口，不需要问人。

---

### 步骤 7｜售后

| 场景 | 规则 | 依据 |
|---|---|---|
| 七天无理由 | 装饰画类适用；**贴身配饰拆封后不适用**，但必须在**下单前**明示 | 消法第 25 条（性质不宜退货需消费者确认） |
| 质量问题 | 无条件退换，运费我方承担 | 产品质量法 |
| 快递丢件/破损 | 24 小时内给方案（补发或退款） | —— |
| 退款 | 原路退回，1–3 个工作日到账 | 微信支付规则 |

**判据**：任意售后，用户 24 小时内收到明确答复（不是"稍等").

## 三、必须公示的四样（电商法要求）

1. **营业执照**（亮照）—— 小程序里要有入口
2. **联系方式**（客服 + 邮箱）
3. **退换货规则**
4. **发票说明**（怎么开、多久开）

> 《电子商务法》第 15 条：电子商务经营者应当在首页显著位置公示营业执照信息。
> **这一条最容易漏，也最容易被投诉。**

## 四、会直接导致下架/处罚的红线

| 红线 | 后果 |
|---|---|
| 类目与实际商品不符（用饰品类目卖食品/化妆品） | 下架 + 扣分 |
| 发货超时（>48h）累计 | 限流 → 下架 |
| 虚假宣传（纯金/手绘/矿物颜料/非遗） | 下架 + 处罚 + 消费者索赔 |
| 用宗教词做功效承诺 | 下架（88 号文） |
| 不亮照、不公示售后规则 | 投诉即查 |
| 诱导好评（返现） | 处罚 |
| 商品无中文标签/无厂名厂址 | 按三无产品处理 |

## 七、还没解决的问题（需要你确认）

1. **执照增项能不能办**——这是全链路的第一颗扣子
2. **供货方能不能开增值税发票**——不能开，就不能合规做
3. **类目到底给不给开**——认证过后我查，查不到就得改卖无人物题材的纹样款
4. **要不要接微信小店**——小店能省掉"发货信息管理"与部分合规工作，但要交保证金且有类目限制；自建支付更自由但要自己做全套
5. **退款由谁操作**——商户号后台退款需要管理员扫码或 API 证书，建议先手工

## 0. 一句话结论

**渠道你有 = 最大的未知数解掉了。但「帮寺庙出售」这五个字必须换成「向藏香厂采购后，以我方名义销售」。**
差别**不在措辞**，在**合同主体**和**钱的方向** —— 后者决定是不是踩《国宗发〔2017〕88 号》。

---

## 1. 三种结构：只有两种能走

| 结构 | 合同相对方 | 钱的方向 | 判定 | 依据 |
|---|---|---|---|---|
| **A 买断自销**（推荐） | 工商注册的经营实体（藏香厂 / 香业公司） | 我们 → 供方（货款）一条；售出收入归我们 | ✅ **绿** | 正常买卖。第 7 条明文承认「场所兴办的经济实体…独立进行财会登记核算并照章纳税」 |
| **B 代销 / 一件代发** | 同上（必须是企业，不是场所本身） | 售出后按**结算价**付货款（不是按销售额抽成） | ✅ **绿**（前提：结算价是货款口径） | 同 A，只是库存风险转移 |
| **C 代运营 / 帮场所卖、抽佣** | 宗教活动场所本身；或按销售额给场所提成 | 钱进场所账户，我们抽佣 / 分成 | ❌ **红** | 第 1 条「不得…以『分红提成』等方式对场所进行商业运作并获取经济收益」；若再宣传成善款/供养 → 第 2 条（不得收取宗教性捐献）+ 第 5 条（不得接受宗教性捐赠） |

> ⚠️ **A/B 与 C 的分界线只有一条**：我们赚的是**进销差价**，还是**从场所收入里分成的佣金**。前者是贸易，后者是"商业运作场所"。
> **「用自己的名字」这一点是对的，而且必须做满** —— 销售主体、店铺名、发票主体、售后主体**全部是我们**。不要出现"受寺院委托""代寺院销售"这类把自己写成宗教主体代理人的表述。

## 2. 向渠道方要什么（六件套，逐条写清为什么要）

| # | 要什么 | 为什么 | 备注 |
|---|---|---|---|
| 1 | **营业执照**复印件（加盖公章） | 确认它是**工商注册的经营实体** —— A/B 结构成立的前提；也是第 7 条"经济实体"的凭证 | 经营范围需含香制品/工艺品/日化等 |
| 2 | **质检报告**（有 **CMA/CNAS** 标识） | 平台对需质检类目的硬要求；也是出事时的免责证据 | 见下方「标准号」 |
| 3 | **标准号**：报告中列明依据的标准 | **定性证据**：按 GB/T 43430-2023 进销 = 家居香品；按宗教用香口径进销 = 佛教道教衍生商品（第 5 条禁止） | 见 §3 |
| 4 | **商标注册证 / 品牌授权书** | 商品页若使用对方品牌名，平台要授权链路 | 若我们贴自己的牌，则需对方出具**代工/贴牌授权** |
| 5 | **地理标志**：核准使用专用标志的公告（**若对方宣称"尼木藏香"**） | 见 §4 的⚠️ —— **专用标志的合法使用人是生产者，不是销售商** | 没有就别写、别贴图 |
| 6 | **非遗相关证明**（若文案要写"非遗"） | Ⅷ-141 项目名 / 保护单位 / 传承人 / 生产性保护示范基地等，写进文案的每一句都要能对上 | 出处见 `data/incense.js` |

### ❌ 别要错的东西

**生产许可证不用要。** 2024 年 5 月《国务院关于调整完善工业产品生产许可证管理目录的决定》（国发〔2024〕11 号）调整后，实施生产许可证管理的产品共 **14 类 27 个品种**（建筑用钢筋、水泥、广播电视传输设备、人民币鉴别仪、预应力混凝土铁路桥简支梁、电线电缆、危险化学品、危化品包装物及容器、化肥、燃气器具、钢丝绳、人造板、特种劳动防护用品、直接接触食品的材料等相关产品）—— **不含熏香/卫生香**。
向对方索要一个根本不存在的证，只会显得不专业，也会让对方怀疑我们没做过这门生意。

## 3. 检测标准（要让报告里出现这些号）

| 标准 | 名称 | 性质 | 状态 |
|---|---|---|---|
| **GB/T 43430-2023** | 《藏香》 | **推荐性国家标准** | 2023-11-27 发布 / **2024-03-01 实施**，现行；ICS **13.120（家用品安全）**，中国轻工业联合会归口；适用于藏香产品的**生产、检验和销售** |
| GB 26386-2011 | 《燃香类产品安全通用技术条件》 | 燃香类通用 | 四川省消委会 2023 年藏香比较试验报告列为依据之一 |
| GB/T 26393 | 《燃香类产品有害物质测试方法》 | 方法标准 | 常用配套 |
| DB54/T 0080-2014 | 《藏香》 | 西藏地方标准 | 比较试验采用其检测项目与限值 |
| DB54/T 0129-2017 | 《地理标志产品 尼木（吞巴）藏香》 | 地方标准 | 涉及地理标志时配套 |

**典型检测项目**（DB54/T 0080-2014 口径）：燃烧安全性能、尺寸、燃烧后甲醛/苯/甲苯/二甲苯浓度、可迁移元素（铅/砷/汞/镉/铬）、烟尘量、产品使用性能（燃尽无自熄）、藏香共有成分。

> 出处：全国标准信息公共服务平台 std.samr.gov.cn（GB/T 43430-2023）；人民网西藏频道（2023-12-19）；四川省消委会《2023 年藏香比较试验报告》；检测机构公开检测项目清单｜**查询日期 2026-10-16**。

## 4. ⚠️ 地理标志：销售方**不能**自己用专用标志

《地理标志产品保护办法》第二十条：产地范围内的**生产者**使用专用标志，需向产地知识产权管理部门申请，经省级审核、国家知识产权局审查合格注册登记并公告后，方可使用。合法使用人包括：经公告核准的**生产者**、集体商标注册人的集体成员、证明商标的被许可人、经登记备案的其他使用人。

**尼木藏香（吞巴藏香）**：国家质检总局地理标志保护产品，2014 年第 136 号公告，批准时间 2014-12-11。专用标志申请路径为「拉萨市质监局 → 自治区质监局 → 质检总局核准公告」。

**对我们的直接影响**：
- ✅ 可以做的：**客观陈述产地**（如"产自西藏拉萨市尼木县"），并可引用公开的地理标志保护产品事实。
- ❌ 不能做的：**在产品页或包装上使用地理标志专用标志图案**（那个 GI 标），除非我们自己是经公告核准的**生产者** —— 我们是经销商，不是生产者。
- **待确认**：是否可由供方出具书面许可，允许我们在**其产品**的页面上使用（一般需供方已获核准并在授权范围内）。**这一条我不替你判断，建议向供方与平台双向确认后再定稿。**

## 5. 商务条件：报价单必须问到的字段

| 字段 | 要问到什么粒度 |
|---|---|
| 出厂价 | **含税 / 不含税**要说死；是否含运费 |
| 起订量 MOQ | 首批最小起订、补货最小起订 |
| 一件代发 | 支持与否、代发费、发货时效、快递 |
| 包材与破损 | 谁承担运输破损、破损率约定、是否提供礼盒装 |
| 供货周期 | 常规款备货天数、断货预警 |
| 结算方式 | 先款后货 / 账期 / 月结 —— **对公转账 + 发票**是"买卖关系"最硬的证据 |
| 素材授权 | 能否使用其产品图、详情页、品牌名（**书面**授权，口头不算） |
| 退换货 | 滞销能否退、质量问题谁担 |

> 🔴 **定价我不替你编。** 等到含税出厂价 + 运费 + 平台费率 + 包装成本出来，我再算毛利与建议零售价。文档里那些（淘宝 ¥54 / 京东 ¥92.30 / 天猫 ¥85.20）是**他人店铺实价锚点**，不是我们的成本。

## 6. 微信小店侧：要办什么

**基础资质（必备四件套 + 1）**：营业执照、法人/经营者身份证件、超级管理员身份证件、银行账户（**企业店必须与主体名称一致的对公账户**）、1 个已实名认证的微信号。
**经营范围**：所售商品/所选行业大类**必须在营业执照经营范围内**（超范围会被驳回）。

**类目**：一级 **文玩文创** → 二级 **香道用品**（《微信小店「二级类目-香道用品」类目管理规则》修订 2025-10-22 / 生效 2025-10-29，准入类型：**开放**）。公开规则列出的三级/四级为：

| 三级 | 四级 |
|---|---|
| 合香珠 / 合香牌 | — |
| 沉香香薰制品 | 燃香、香囊/香包、精油 |
| 檀香香薰制品 | 燃香、香囊/香包、精油 |

> ⚠️ **待确认（我不猜）**：藏香多为**线香形态 + 多味藏药材合香**，字面上不落在"沉香/檀香香薰制品"里。**请在微信小店后台「类目查询」工具里搜「香道用品」看完整类目表**，确认线香的准确落点（是否有"其他香薰制品/合香"项），再定。
> **保证金与技术服务费**：按《微信小店保证金条款》《小店类目保证金额度》《技术服务费一览表》**以后台显示为准**（我此前查到的"0 元开店 + 零保证金 + 新商家前 100 万 1%"是 2026-10-15 的口径，**会变，以你后台为准**）。

## 7. 命名红线（第 2 条：严禁公司企业冠以佛教、道教名称）

**店铺名 / 品牌名 / 公司名 / 小程序名 / 视频号小店名**一律不得含：寺、庙、佛、僧、菩萨、活佛、加持、开光、功德、香火、法门、般若、菩提、舍利、经幡、转经 —— **也不得冠以寺院名**。

【标准】执行 GB/T 43430-2023《藏香》国家标准

## 9. 需要你拍板的 5 件事

1. **渠道的合同相对方是谁**（藏香厂？香业公司？还是寺院本身）→ 决定 A/B/C 哪一种。
2. **钱怎么走**：买断还是代销结算；**绝不能是分成/抽佣**。
3. **品牌名定哪个**（当前候选"藏趣"），以及是**贴我们的牌**还是用对方品牌（后者要授权书）。
4. **含税出厂价 + MOQ + 是否一件代发** —— 给我这三个数，我算毛利与定价。
5. **微信小店类目落点**（见 §6 待确认项）—— 需要你进后台查。

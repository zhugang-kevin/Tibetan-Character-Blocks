# 备案工作流（ICP / 小程序备案）

> 适用范围：本项目自营 B2C 小程序 + H5 + 自建服务端。
> **所有条目标注来源与核验状态**。带「待核验」的表示我未在官方页面确认，执行前必须自己去查。

---

## 一、先搞清楚：这个项目要备几个案

| # | 类型 | 用途 | 谁管 | 状态 |
|---|---|---|---|---|
| **1** | **小程序备案** | 微信小程序上架的前置条件 | 微信公众平台（走通信管理局）| 必须 |
| **2** | **ICP 备案（网站）** | 服务端 API 域名被微信访问 | 域名服务商（阿里云/腾讯云）→ 通信管理局 | 必须 |
| **3** | **公安联网备案** | ICP 备案通过后 30 日内 | 全国互联网安全管理服务平台 | 必须（法定）|
| 4 | 经营性 ICP 许可证 | 若做「平台/多商家抽佣」 | 通信管理局 | **不做**（自营 B2C 不需要）|

**关键区别**：虚拟支付、广告**都不要** ICP 许可证；只有「电商平台/多商家入驻/平台抽佣」才要。
本项目是**自营 B2C**，不做平台模式 → **不办经营性许可证**。

---

## 二、执行顺序（不能颠倒）

```
① 域名实名 + 域名备案（ICP）
        ↓  备案通过后
② 服务端配置 HTTPS（TLS ≥ 1.2）
        ↓
③ 小程序备案（微信后台提交）
        ↓  备案通过
④ 小程序提审上架
        ↓
⑤ 公安联网备案（ICP 通过后 30 日内）
```

**为什么不能倒**：小程序备案要填**服务端域名**，域名没备案，小程序备案会被打回。

## 四、小程序备案的具体操作

### 4.1 入口

微信公众平台 → 登录小程序后台 → **设置 → 基本设置 → 小程序备案**

### 4.2 填写要点（这几项最容易被打回）

| 字段 | 怎么填 | 为什么 |
|---|---|---|
| **服务内容类型** | 选**教育 / 在线教育**或**工具**类，**绝不选"游戏"** | 选游戏会触发版号要求 |
| **服务内容描述** | 强调「藏文识字学习工具」「文化知识科普」，不写"消除游戏""关卡""闯关" | 描述与类目必须一致 |
| **是否含虚拟支付** | 如实填（本项目有 1/3/6 元虚拟礼物）| 隐瞒会被驳回 |
| **是否含用户生成内容** | 无 | — |

### 4.3 审核周期

- 微信初审：1–3 个工作日（待核验）
- 通信管理局审核：**1–20 个工作日**（法定上限 20 日）
- **总计预留 30 天**

## 五、我方能提前做的准备（不依赖外部审批）

### 5.1 文案与类目一致性检查

备案描述里写的功能，必须和小程序实际功能对得上。**这是最常见的驳回原因。**

**必须做一次全量自检**：

| 检查项 | 判定标准 |
|---|---|
| 小程序名称 | 「藏趣方块」不含宗教/游戏暗示 ✅ |
| 类目 | 教育/工具，非游戏 |
| 首页文案 | 不出现「关卡」「闯关」「PK」「排行榜」等游戏化词 |
| 备案描述 | 与实际功能逐条对应 |

**注**：项目里已有去游戏化门禁（把「关」改成「课」），但**代码注释里仍有「关卡」**，备案前需再扫一遍玩家可见文本。

### 5.2 技术前置条件（现在就能验证）

| 条件 | 官方要求（待核验） | 现在怎么验 |
|---|---|---|
| HTTPS | 必须，不支持 HTTP | 服务端配好证书后 `curl -I https://域名` |
| TLS 版本 | ≥ 1.2 | `openssl s_client -connect 域名:443` |
| 不能是 IP/localhost | 必须是备案域名 | 检查 `config/*.js` 里的 apiBase |
| 不支持父域名 | 必须配具体子域名 | 如 `api.xxx.com` 而非 `xxx.com` |
| 端口 | 可配，但推荐 443 | 同上 |

### 5.3 服务端代码现状核查

```
server/            ← 已有 Node 服务端
config/pay.js      ← 支付配置存在（offerId 空）
```

**待做**：确认 `apiBase` 是否已指向真实域名，还是仍是 `localhost`。

## 八、常见驳回原因（提前避坑）

| 驳回原因 | 怎么避免 |
|---|---|
| 服务内容描述与实际不符 | 描述逐条对应真实功能 |
| 类目选错（选了游戏）| 选教育/工具 |
| 主体信息与营业执照不一致 | 逐字核对 |
| 域名未备案就提小程序 | 先备案域名 |
| 承诺书未盖章/章模糊 | 彩色扫描，章清晰 |
| 负责人手机号与身份证不匹配 | 用本人实名号 |

## 第三部分：线上服务器部署（照 `docs/部署-dorjea服务端.md` 执行）

### 3.1 部署步骤（每条命令可复制）

```bash
# 1. Node ≥ 22.5（node:sqlite 依赖）
node -v

# 2. 拉代码（只需 server/）
sudo mkdir -p /opt/dorjea && sudo chown $USER:$USER /opt/dorjea
cd /opt/dorjea
git clone https://github.com/zhugang-kevin/Tibetan-Character-Blocks.git .
cd /opt/dorjea/server

# 3. 数据目录
sudo mkdir -p /var/lib/dorjea && sudo chown $USER:$USER /var/lib/dorjea && chmod 750 /var/lib/dorjea

# 4. 环境变量（密钥走 /etc/dorjea/env，权限 640，绝不写进 systemd）
sudo mkdir -p /etc/dorjea
sudo tee /etc/dorjea/env > /dev/null <<'EOF'
PORT=8300
DB_PATH=/var/lib/dorjea/pay.db
ORDERS_DB=/var/lib/dorjea/orders.db
TELEMETRY_TOKEN=请换成随机32位(openssl rand -hex 32)
WX_APPID=wx3378038122ee9d54
WX_APPSECRET=请填
WX_OFFER_ID=请填
WX_APPKEY_PROD=请填
WX_APPKEY_SANDBOX=请填
MAX_BODY_BYTES=1048576
TELEMETRY_MAX_BYTES=10485760
TELEMETRY_MAX_PER_MIN=120
EOF
sudo chown root:root /etc/dorjea/env && sudo chmod 640 /etc/dorjea/env

# 5. systemd 服务（详见部署文档 §4，User=www-data，EnvironmentFile=/etc/dorjea/env）
# 6. Nginx 反向代理（详见部署文档 §5，443 ssl + proxy_pass 127.0.0.1:8300）
# 7. SSL 证书（备案已过，用 HTTP-01 可全自动续期）
sudo certbot certonly --webroot -w /var/www/certbot -d 你的域名 -d www.你的域名
```

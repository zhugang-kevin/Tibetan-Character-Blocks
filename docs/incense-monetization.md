## 0. 结论先行

1. **市场确实更大 —— 而且比我想的更契合本项目。** 尼木县（藏香之源）2026 年 1-7 月藏香产业总产值 **2431.94 万元**、销售额 **1720.83 万元**；且**尼木正是藏文字创制者吞弥·桑布扎的故乡** —— 藏文与藏香**同源**。别人卖藏香没有这层叙事，我们有。

2. **但「藏区各个寺庙的藏香」这个卖点必须换掉。** 国家宗教局等 **12 部门**《关于进一步治理佛教道教商业化问题的若干意见》（**国宗发〔2017〕88 号**）明文禁止我们这类主体这么做（详见 §2）。踩线不是「可能被警告」，是**明令禁止**。

3. **🔄 更正（2026-10-15 二次查证）：寺庙藏香**可以做**，只是必须走「非遗通道」而不是「宗教通道」。**
   我上一版说得太绝对（「寺庙藏香卖点必须换掉」）—— 查证后发现：
   **「藏香制作技艺（敏珠林寺藏香制作技艺）」本身就是 2021 年第五批国家级非物质文化遗产**
   （项目序号 924 / 编号 **Ⅷ-141**），而且**保护单位是西藏扎囊县文化局**（政府文化部门，不是宗教团体）。
   也就是说：**寺名在官方非遗名录里是项目名的一部分**，客观陈述它是**文化遗产语境**，不是「以佛教名义做商业宣传」。
   → 文案**主语写「非遗项目」**，寺名作**产地与源流的客观陈述**。详见 §3。

4. **四层官方背书，比「某寺出品」硬得多**（后者根本写不进文案）：
   **国家级非遗 2008（藏香制作技艺）+ 国家级非遗 2021 第五批 Ⅷ-141 + 国家地理标志 2014（尼木藏香）+ 藏文同源（吞弥·桑布扎）**，
   再加 **189 户制香户 / 4077 人增收**的帮扶叙事。全部公开可查、官方授予。

我们小程序教的就是藏文。**「你学的这套字母，和手里这炷香，是同一个人、同一个县、同一年传下来的。」** 这条叙事别人抄不走。

## 2. 合规红线：为什么不能写「寺庙出品」

**依据**：国家宗教局、中央宣传部、中央统战部、中央网信办、国家发改委、公安部、财政部、住建部、税务总局、旅游局、证监会、文物局 **12 部门**联合印发
《关于进一步治理佛教道教商业化问题的若干意见》**国宗发〔2017〕88 号**（2017-11-03），中国政府网可查。

| 条款 | 原文要点 | 对我们的杀伤 |
|---|---|---|
| **第 1 条** | 严禁商业资本介入；不得投资或承包经营佛教道教活动场所；不得以「股份制 / 租赁承包 / **分红提成**」等方式商业运作并获取经济收益 | 想做「与寺庙分成」的模式 → 直接违规 |
| **第 2 条** | **禁止以佛教道教名义进行商业宣传**；严禁行业协会、商会、公司企业冠以佛教道教名称；严禁假冒教职人员骗取钱财 | 「寺庙藏香 / 寺院监制 / 开光加持」做卖点 → 直接违规 |
| **第 5 条** | **非宗教活动场所、非宗教团体、非宗教院校和个人设立的互联网宗教信息平台**，不得开展「网上烧香」「网上礼佛敬佛」、网上功德箱募款**和售卖佛教道教衍生商品**等活动 | 我们是商业主体设立的互联网平台 → **卖「宗教用品」定性风险极高** |
| 第 6 条 | 宗教活动场所**内**可以经销佛教道教用品、艺术品和出版物（收益用于场所自养与公益） | 这条是**给寺庙的许可，不是给商家的**。不能反过来用 |

> ⚠️ 本项目 [`privilege-system-v1.md`](privilege-system-v1.md) 早在 2026-10-04 就写死了同一条：
> 「**排除宗教活动场所与文物景区**（宗教场所不得商业联动），只对接周边经营主体」，并由 validate 自检脚本硬拦。
> 现在这条从「权益中心的局部规则」升级为**全项目的宗教商业化红线**，见门禁 §67。

**叠加风险（必须知道）**：小程序本身已有「六字真言音频」「点灯祈愿」「经书经文背景」等藏传佛教文化元素。
目前它们挂在「**藏文学习 / 藏文化**」定位下，是文化教育内容；一旦开始售卖被认定为**宗教用品**的商品，
整体被认定为「互联网宗教信息服务」的概率会上升 —— 那需要**省级以上政府宗教事务部门审核同意**（第 5 条 +《互联网宗教信息服务管理办法》）。
**所以更要走「非遗 / 地理标志 / 文化」路线，主动远离宗教定性。**

## 2.5 合规通道：走「非遗」，不走「宗教」（本轮的关键更正）

| | 宗教通道 ❌ | **非遗通道 ✅** |
|---|---|---|
| 主体 | 宗教活动场所 | **西藏扎囊县文化局（政府文化部门）** / 尼木县政府 |
| 名义 | 以佛教道教名义宣传（88 号文 第 2 条 禁止） | 国家级非遗项目（受《非物质文化遗产法》规范） |
| 卖方 | 商业资本介入、分成（第 1 条 禁止） | **向生产厂采购**（买卖关系，不是分成） |
| 帮扶 | 「帮扶某寺」（场所） | **帮扶制香的人**：189 户制香户、4077 名群众 |

**支点事实（中国非物质文化遗产网 ihchina.cn，查询 2026-10-15）**：

- 项目名：**藏香制作技艺（敏珠林寺藏香制作技艺）**
- 编号：**Ⅷ-141** ｜ 序号 924 ｜ 公布时间 **2021（第五批）** ｜ 类别 传统技艺
- 申报地区：西藏自治区山南市 ｜ **保护单位：西藏扎囊县文化局（西藏扎囊县文物局）**
- 传承谱系：第一代德达林巴 → 第八代当曲旦增，**400 多年**
- 原料：白檀香、紫檀香、丁香、诃子、毛诃子、土木香、藏红花等 **30 多种天然藏药材**
- 保护方式：「主要**通过敏珠林寺藏香厂的日常生产实践**得以保护传承」

> ⚠️ 仍不可碰：**开光 / 加持 / 高僧 / 功德 / 供佛 / 礼佛 / 寺院监制 / 寺庙出品**
> （门禁 `scripts/test-religion-compliance.js` 机械拦，16 词 + 句式双重拦截，含反例自测）。
> 也**不可作功效宣称**（治病 / 安神 / 净化空气 / 提高免疫力 …）—— 非药品宣称疗效是《广告法》的麻烦。

## 3. 合规卖法：四层官方背书（寺名只作产地与源流的客观陈述）

| 层 | 内容 | 能不能写进文案 |
|---|---|---|
| ① 技艺 | 藏香制作技艺，**2008 年列入国家级非物质文化遗产代表性项目名录** | ✅ 能，且是官方授予 |
| ①b 技艺 | **藏香制作技艺（敏珠林寺藏香制作技艺）**，2021 第五批国家级非遗 **Ⅷ-141** | ✅ 能（**官方名录原名**，保护单位是政府文化局） |
| ② 产地 | 尼木藏香，**2014 年获评国家地理标志保护产品** | ✅ 能，且是官方授予 |
| ③ 文化同源 | 藏文与藏香同为**吞弥·桑布扎**所创；尼木 = 「藏文鼻祖之乡、藏香文化之源」 | ✅ 能，历史事实 |
| ④ 工艺细节 | 柏木香砖粉碎 → 雪山泉水调香泥 → 古方配伍藏药材 → 牛角手工挤香 → 自然阴干 3-4 天，**不添加化学胶/工业香精/助燃剂** | ✅ 能（客观工艺描述） |
| ⑤ 人 | 189 户手工制作户、带动 4077 人增收 | ✅ 能（消费帮扶叙事，最动人且合规） |
| ❌ 寺庙 | 「某某寺出品 / 寺院监制 / 高僧加持 / 开光」 | ❌ **一律不许**（门禁 §67 硬拦） |

**文案示例（合规版）**：
> 「你刚学会的这套藏文字母，和手里这炷香，来自同一个人。
> 1300 年前，吞弥·桑布扎在尼木创制藏文，也在此钻研藏香。
> 尼木藏香：2008 年国家级非物质文化遗产，2014 年国家地理标志保护产品。
> 柏木水磨、雪山泉水、牛角手工挤香、自然阴干四天 —— 不加化学胶与工业香精。
> 全县 189 户手工制香户，这一盒，是在养活一门手艺。」

## 5. 一手货源线索（真实存在，不是我编的）

- **敏珠林寺藏香厂**（首选，最贴近你要的「寺庙藏香」）—— 1983 年建厂，位于山南市扎囊县扎其乡塔巴林村；
  占地 2300 余平方米，**年均产量 20 余万盒、年均销售总额 400 余万元**；
  2013 年列入自治区级非遗名录，2014 年被评为自治区级非遗生产性保护示范基地；
  销售网络以拉萨为中心，连接山南、昌都、日喀则及北京、上海、湖南、四川、广东。
  **它是「以寺养寺」背景下建起来的生产实体，也是 Ⅷ-141 项目的主要传承载体** ——
  合规路径是**向它采购**（买卖关系），不是与它分成。
  出处：扎囊县人民政府网 xzzn.gov.cn（2019-09-18）｜查询日期 2026-10-15
- **西藏藏之梦香业有限公司** —— 极狐商城首批上架的 5 款尼木藏香**全部来自该公司**（搜狐 2026 年报道），
  已有电商供货经验，可作为尼木线的洽谈对象。
- 尼木县另还有 **1 家企业 + 4 家合作社 + 189 户手工制作户 + 1 个产业园**（拉萨市委网 2026-09）：
  若要走「消费帮扶 / 助农」叙事，对接县里的产业园或合作社比对接单户更稳（开票与资质）。

**⚠️ 我不掌握你的进货成本与渠道，以上只是公开信息里的线索，不构成商务建议。**

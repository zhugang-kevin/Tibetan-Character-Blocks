# 藏香厂家准入验收表（可直接复制发给对方）· 2026-10-16

> 触发：用户拍板「**直接找有资质的厂家**」（D127）
> 结论索引 [`DECISIONS.md`](DECISIONS.md) · 配套 [`incense-sourcing-checklist.md`](incense-sourcing-checklist.md)、[`incense-handmade-compliance.md`](incense-handmade-compliance.md)
> 用法：**把 §1 的 6 条原样发给厂家**，让对方逐条答复；§2 的 6 条用于商务确认；§3 是红旗，出现任意一条直接换人。

---

## 1. 资质硬条件（6 条，缺一不可）

> 以下可直接复制发给厂家：

```
您好，我们准备在微信小店上架藏香，需要先确认贵司资质，烦请逐条回复：

1) 请提供【营业执照】照片/扫描件（需看清经营范围）。
2) 经营范围是否包含香制品 / 工艺品 / 日化或家居用品？具体是哪一项？
3) 产品执行什么标准？是否执行 GB/T 43430-2023《藏香》？
   包装/标签上是否印有该标准号？
4) 是否有第三方质检报告？是否具备 CMA 或 CNAS 标识？
   报告覆盖哪些项目（燃烧安全 / 甲醛·苯·甲苯·二甲苯 / 可迁移重金属）？
   报告有效期到什么时候？
5) 产品包装/标签上是否印有：产品名称、生产厂厂名和厂址、
   规格/数量、生产日期、质量检验合格证明？能否拍一张标签照片？
6) 能否开具增值税专用发票？是一般纳税人还是小规模纳税人？
```

### 逐条为什么

| # | 要什么 | 依据 / 为什么 |
|---|---|---|
| 1 | 营业执照 | 合同相对方必须是**工商注册的经营实体**（门禁 §5②）—— 没有它，"买断自销"这个合规结构不成立 |
| 2 | 经营范围覆盖所售类目 | 微信小店要求：所售商品/所选行业大类**必须在营业执照经营范围内**，超范围会被驳回 |
| 3 | 执行 **GB/T 43430-2023《藏香》** | 🔴 **定性证据**：按国标进销 = 家居香品；按宗教用香口径 = 佛教道教衍生商品（88 号文第 5 条禁止）。**必须印在包装上** |
| 4 | **CMA/CNAS** 质检报告 | 平台对需质检类目的硬要求；也是出事时的免责证据。项目建议：燃烧安全性能、尺寸、燃烧后甲醛/苯/甲苯/二甲苯、可迁移元素（铅/砷/汞/镉/铬）、烟尘量、使用性能（燃尽无自熄）、藏香共有成分 |
| 5 | 包装标识齐全 | 《产品质量法》**第 27 条**：合格证明 + 中文产品名称、生产厂厂名和厂址 + 规格/等级/主要成分 + 生产日期（限期使用品）。**第 33 条**销售者应建立进货检查验收制度；**第 36 条**销售者所售产品标识同样须合规；**第 54 条**情节严重责令停止销售 + 货值 30% 以下罚款 + 没收违法所得 |
| 6 | 增值税专用发票 | 进项票与成本核算；也是对公付款、证明买卖关系的凭证 |

### ❌ 别要错：生产许可证不用要

**藏香不需要工业产品生产许可证。** 2024 年 5 月《国务院关于调整完善工业产品生产许可证管理目录的决定》（**国发〔2024〕11 号**）调整后，实施生产许可证管理的产品共 **14 类 27 个品种**（建筑用钢筋、水泥、广播电视传输设备、人民币鉴别仪、预应力混凝土铁路桥简支梁、电线电缆、危险化学品、危化品包装物及容器、化肥、燃气器具、钢丝绳、人造板、特种劳动防护用品、直接接触食品的材料等相关产品）—— **不含熏香/卫生香**。

**所以：如果厂家拿不出"生产许可证"，这是正常的，不代表没资质。** 向对方索要一个根本不存在的证，只会显得我们没做过这门生意。

## 2. 商务确认（6 条）

| # | 问什么 | 为什么 |
|---|---|---|
| 1 | 含税出厂价 / 结算价 | 定价的三个输入之一 |
| 2 | MOQ（首批 + 补货） | 决定资金占用 |
| 3 | 是否支持**一件代发** | 决定要不要自建仓储发货 |
| 4 | 供货周期与断货预警 | 电商断货会掉权重 |
| 5 | **能否贴我们的牌（OEM）？授权书能否出具？** | 决定品牌归属（我们"用自己的名字卖"的前提） |
| 6 | **是不是非遗项目保护单位 / 生产性保护示范基地？** | 决定能不能写"非遗"—— 写错就是引人误解的商业宣传 |

## 3. 🚩 红旗（出现任意一条 → 换人）

- 只能提供**散装 / 裸装**，不肯印厂名厂址与标准号
- 质检报告的**送检单位不是它自己**，且说不清来源
- 拒绝提供**配料表 / 主要成分**
- 只收**私户**、无法开票
- 主动建议写「开光 / 加持 / 供佛 / 治病 / 安神」——说明它自己就不懂红线，合作会连累你

---

## 4. 🔴 特别提醒：别去要一个不存在的证

结合上面 §1 第 1 条与前面几轮的结论，再强调一次，避免再次误解：

- **不需要**：工业产品生产许可证（目录里没有熏香）
- **不需要**：任何"认证"来证明产品是藏香 —— 靠**执行标准号**定性
- **不能要 / 不能用**：地理标志专用标志（合法使用人是经核准的**生产者**，我们是经销商）、
  Ⅷ-141 非遗项目背书（那是敏珠林体系的项目）、寺院名义背书（88 号文第 2 条）

**要的只有那 6 条：执照、经营范围、执行标准、检测报告、包装标识、发票。**
这六条手工香同样给得出 —— 所以真正的门槛从来不是"认证"，而是**"有没有一个合法的经营主体 + 敢不敢把标识印在包装上"**。

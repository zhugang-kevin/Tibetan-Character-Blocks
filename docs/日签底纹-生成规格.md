# 日签祝福卡 · 吉祥八宝底纹图 · 生成规格

> 用途：作为「雪域日签」祝福卡的**满幅底纹**，最终以 **16% 透明度**铺在米色内页上，文字压在最上层。
> 目标设备尺寸固定为 **750×1000 px（3:4）**，请按这个比例出图。

## 二、反向提示词（必填，这是上一版最关键的问题）

```
text, letters, chinese characters, tibetan script, labels, captions,
watermark, logo, signature, numbers, border frame, drop shadow,
```

**为什么要反向排除文字**：你上一版参考图（`吉祥八宝 背景.jpeg`）自带

## 三、硬性约束（逐条对照验收）

| # | 约束 | 判定方法 |
|---|---|---|
| 1 | **不能有任何文字**（中文/藏文/数字/署名） | 放大到 100% 逐块扫一遍 |
| 2 | **不能有外框** | 卡本身有藏红金框，底纹再加框会双重框 |
| 3 | **不能有背景色块/渐变** | 底色必须干净，否则 16% 叠加会显脏 |
| 4 | **线条要细、要淡** | 想象它要退到 16% 透明度仍不糊 |
| 5 | **八宝齐全** | 法轮、宝伞、金鱼、宝瓶、莲花、海螺、吉祥结、胜利幢，一个不缺 |
| 6 | **构图留白** | 中央区域（放藏文的位置，约画面上 1/3）要留空，**不要把最复杂的元素放中间** |
| 7 | 比例 3:4 | 750×1000 或 1500×2000 |

## 四、推荐参数

| 项 | 建议 |
|---|---|
| 尺寸 | 750×1000 或 1500×2000（3:4）|
| 风格 | 矢量线稿 / 扁平插画 / flat line art |
| 主色 | 金 `#C9A227` ~ `#B7950B`，线宽统一 |
| 底色 | 米色 `#FBF3DF` ~ `#F5EBD5`（或纯白，我在代码里可调）|
| 饱和度 | 低（会再压到 16%，太高会脏）|
| 细节密度 | 中低（细节过多缩小后变灰块）|

## 五、构图建议（关键）

```
┌──────────────────┐
│  伞   轮   瓶     │  ← 上方一排 3 个
│                  │
│      （留白）      │  ← 中央留空：藏文 76px 要放这里
│                  │
│  莲  结  鱼  幢   │  ← 下方一排 4 个
│                  │
│        螺         │
└──────────────────┘
```

**中央必须留白** —— 那里要放 76px 的藏文大字，纹样不能来抢。

也可以做成**四角散布 + 中央空**的布局，比均匀铺满更适合当底纹。

## 六、交付后我会怎么用

1. 你给图（JPG/PNG 都行，**不要压缩过度**）
2. 我缩到 600 宽 → base64 内联（约 100–150KB）
3. `ctx.globalAlpha = 0.16` 铺满内页
4. 文字画在上层

**如果出来的图偏浓，我可以把 alpha 调到 0.10–0.12；偏淡就调到 0.20。这个不用重出图。**

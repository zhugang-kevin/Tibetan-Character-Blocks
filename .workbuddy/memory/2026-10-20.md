### 关键判断：**用户是对的，而且根因在结构上**
现状 = **点选任意两个相同牌**（不要求相邻）→ 属于**对对碰/连连看**，不是三消。
三消的爽感来自两台引擎：**连锁**（下落后再触发新三消）+ **特效阶梯**（3/4/5 消 → 不同道具）。
我们两台都没有 → 所以怎么调分都没用，玩家每一步没有决策。

### 查到的行业通行范式（2026-10 检索，多份来源一致）
- **五步循环**：交换 → 匹配 → 消除 → 下落 → **连锁**
- **特效阶梯**：3 连普通 · **4 连一线→条纹（清整行/列）** · **L/T 形→爆炸（3×3）** ·
  **5 连一线→彩虹（清全场同色）** · 两特效交换→组合
- **挑战来源**：限步数 + 关卡目标（分数/收集/清障/运送）+ 障碍（多层冰/藤蔓/毛球/毒液/传送门）
- **参数**：元素 **5 种**为宜；棋盘 **8×8** 是黄金尺寸（我们现有 25–49 格，偏小）

### 🔴 实测确认的硬骨头（不是估算）

## ⛔ 「现在就做切换」→ 做了数据层，但**实测证明不能切**（有硬数据）

用户要求立刻切换。我按 A(配比) → B(盘面生成) → C(150 关验证) 推进，
在 C 一步**跑出了决定性的反证**：

| 指标 | 结果 |
|---|---|
| 格数能被 3 整除（才可能铺成纯 3 倍数） | **70 / 150** |
| 格数不能被 3 整除（**必然留 1~2 张永远消不掉**） | **80 / 150** |
| 实际生成后「盘面每种元素都是 3 的倍数」 | **14 / 150** |
| 开局就**没有任何合法交换** | **41 / 150** |

### 根因（数学，不是实现疏忽）
1. 配比是 3 的倍数，但**格数**不是（5×5=25，25%3=1）→ 盘面必然有元素张数不是 3 的倍数
2. 一次消除拿掉的是**整条线**（≥3，长度任意）→ 余量会停在 1 或 2 → 永远消不掉
3. **所以三消从不以「清空盘面」为通关条件** —— 行业标准是「限步数 + 目标」

### 结论：我原来的 P1/P2 分期是错的
「三消机制」和「目标化」**必须作为一个整体上线**，不能分两次。
**页面绝不能现在切** —— 切了就是 80 关直接不可通关。

1. 100 关的棋盘从 3×3/4×4 提到 **≥6×6**

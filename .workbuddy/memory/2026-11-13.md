### 🔴 关键教训：Python open('w') 在 Windows 会把 LF 写成 CRLF
改名脚本用 `open(fp,'w',encoding='utf-8')` 重写文件，Windows 默认 newline 转换，
把 game.js 的 LF（HEAD 是 1610 个 LF、0 个 CRLF）全写成了 CRLF。
→ 变异测试 patch() 的锚点写 `\n`，indexOf 匹配不到 `\r\n` → 假「锚点失效」，37 变异 6 个假红。
修法：`scripts/test-ad-runtime-mutation.js` 的 patch() 做换行归一化（匹配前两边都转 \n，写回还原）。
🔴 以后 Python 批量重写文件，**必须 `open(fp,'w',encoding='utf-8',newline='\n')`** 保持原换行，
否则会破坏所有依赖精确字符串匹配的门禁（变异测试 / 断言）。

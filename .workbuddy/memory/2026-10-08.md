### 藏文字形（重要工艺结论）
本机 Pillow **没有 Raqm**（`features.check('raqm')==False`）→ 复杂文种无法整形，直接画会把 ྲ/ི/ེ 排成线性。
改用 **headless Chrome + 字体 base64 内嵌**（`assets-src/fonts/NotoSerifTibetan-Bold.ttf`，OFL）渲染，
字形与 App 内 `font-family:'Noto Serif Tibetan'` 一致；HTML 的 `background-clip:text` 在本机 Chrome 丢填色（只剩描边），
改 **SVG `<text>` + `linearGradient`** 才稳。藏文 ink 不居中（尾部 ་ 有右空边）→ 一律「裁到墨迹再居中」。

### 踩坑（都在代码注释里留了痕）
- **RGBA 当自己的 mask 去 paste → alpha 被应用两次**（15/255 塌成 1/255），图案静默消失；正解 = 单通道 alpha + `Image.composite`。
- 屋顶小亭子的梯形画在了**屋面之下**（+h 写成 -h）→ 只剩细尖露头；SVG `scale()` 与 viewBox 叠加 → 4× 渲染只截到左上角。
- 母图/派生图 256 色量化在大面积渐变上必然出现**色阶断层** → Logo 改**全平色**（顺带更贴规格书「扁平精致」）。
- **headless 里 CSS 动画会冻结**：结算页画卷 `scaleY(.06)` 起手被冻住 → 截图与 `getBoundingClientRect` 全被压成 6%，
  一度误判为「排版塌了」。纪律：截图/量尺寸前注入 `animation:none!important`，并用 `scrollHeight`/`offsetTop`（不受 transform 影响）。

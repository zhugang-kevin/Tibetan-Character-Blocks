## D123 · 用户：「寺庙的藏香我们自己有渠道，或者用自己的名字来帮助寺庙出售藏香」

**好消息**：渠道用户自己有 → 货源这个最大未知数解掉了。
**但「帮寺庙出售」必须换成「向藏香厂采购后以我方名义销售」** —— 差别不在措辞，
在**合同主体**与**钱的方向**。

### 三种结构（只有两种能走）
- **A 买断自销 ✅**：合同相对方是工商注册的经营实体（藏香厂/香业公司），资金只有「我们 → 供方货款」一条。
- **B 代销 ✅**：按**结算价**付货款（不是按销售额抽成）。
- **C 代运营/帮场所卖/抽佣 ❌**：88 号文第 1 条「不得…以『分红提成』等方式对场所进行商业运作并获取经济收益」；
  若宣传成善款/供养 → 第 2 条（不得收取宗教性捐献）+ 第 5 条（不得接受宗教性捐赠）。
- **分界线只有一条**：我们赚的是**进销差价**，还是**从场所收入里分成的佣金**。

### 本轮查到的两条硬依据（此前没查到，非常关键）
1. **88 号文第 7 条**：「佛教道教团体、场所**兴办的经济实体**，要按照国家有关规定
   **独立进行财会登记核算并照章纳税**」→ 这正是「**向寺院办的藏香厂采购**属正当商事行为」的来源。
   所以「寺庙的藏香」与合规**不冲突**，冲突的只是「代场所经营并按销售额分成」。
2. **GB/T 43430-2023《藏香》国家标准**（2023-11-27 发布 / **2024-03-01 实施**，推荐性国标，
   中国轻工业联合会归口，**ICS 13.120 家用品安全**，适用于藏香的生产/检验/销售；
   西藏首个特色民族手工艺类国家推荐性标准）。
   → **比非遗通道更硬**：非遗解决"能不能提这个技艺"，国标解决"产品按什么口径被定性"。
   按 GB/T 43430-2023 进销 = 家居香品；按宗教用香口径 = 佛教道教衍生商品（第 5 条禁止）。
   → **商品页必须写出所执行的标准号**，那是定性证据，不是凑字数。

### 命名红线（第 2 条「严禁公司企业冠以佛教、道教名称」）
店铺名/品牌名/公司名/小程序名/视频号小店名不得含 寺、庙、佛、僧、菩萨、活佛、加持、开光、
功德、香火… **也不得冠以寺院名**。候选 `brand.name = '藏趣'`（待用户确认）。

## D124 · 货源改为「民间家庭作坊」（用户：「那么我们选择民间的家庭作坊藏香吧」）

### 合规其实变松了
家庭作坊与宗教主体无任何关联 → 88 号文第 1/2/5 条基本不适用；帮扶叙事天然成立（对象本就是制香户）。
D123 的 A/B/C 结构判定与「买断自销」结论继续有效。

### 🔴 但换来三个更硬的坑
1. **三无产品不能卖**（《产品质量法》第 27/33/36/54 条）：包装必须有合格证明 + 中文产品名称/
   厂名厂址 + 规格等级主要成分 + 生产日期；**销售者同样有责**（第 33 条进货验收、第 36 条标识），
   第 54 条情节严重可责令停止销售 + 货值 30% 以下罚款 + 没收违法所得。
   → 作坊必须有个体户执照，包装印 **厂名厂址 + GB/T 43430-2023 + 合格证明 + 生产日期**；**裸装散香不碰**。
2. **发票**：已办税务登记的小规模纳税人（含个体户）可**自开专票**（税务总局公告 2019 年第 33 号）；
   未达起征点可放弃免税开专票（**2026 年第 4 号公告**，2026-01-01 施行）；**未登记自然人只能税局代开**。
   → 建议让作坊办个体户执照 + 税务登记（能开票 + 能签合同 + 对公留痕）。
3. **质检报告**：作坊拿不出 → **我们送检**。反直觉但正确：微信小店要求送检单位与**商家主体一致**，
   所以用我们自己名义送检比作坊旧报告更合规。
   实价线索（2026-10-16 查询，差异 5-10 倍，**不替用户选**）：企来检 200-5000 元（单项 100-500）；
   必锐基础三项 3000-5000 元；中科检测（广州）标价 1000 元/件（3 个工作日出 CMA 章）。

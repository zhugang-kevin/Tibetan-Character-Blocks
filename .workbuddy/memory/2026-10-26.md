## 📝 dorjea.cn 备案流程（2026-10-29 22:45）

### 结论：可以，同一主体下能备案多个域名
`guixinkeji.cn` 备案通过后，`dorjea.cn` 走**「新增网站」**，不用重建主体。

**关键概念区分：**
- **主体备案**（营业执照）→ 一次就够，`guixinkeji.cn` 已经建好了
- **网站备案**（每个域名一条）→ **每个域名都要单独一条**

所以 dorjea.cn 是「在已有主体下新增一个网站」，不是「重新备案」。

### 流程（腾讯云）
1. 登录腾讯云 → 备案控制台
2. 点「**新增网站**」（不要点「新增主体」）
3. 填 dorjea.cn，网站名称建议「藏趣方块」（不能含"游戏"二字，会被要求提供版号）
4. 服务内容选「**其他**」或「**文化娱乐**」，**不要选"游戏"**
5. 上传：营业执照、法人身份证、域名证书
6. 人脸核验（腾讯云 App）
7. 提交管局
8. **7–20 工作日**

### 🔴 一个容易踩的坑
**网站名称里不要出现"游戏"二字。**
选了"游戏"类目会被要求提供《网络文化经营许可证》或版号，**科技公司没有**。
我们的定位是「藏文化学习工具」+「文化产品展示」，写「藏趣方块」即可。

- **能**用非标端口 + IP 直连做内部测试

## 🔴 关键更正：服务器阿里云，备案在腾讯云（2026-10-29 22:47）

### 用户澄清

- **域名 = 腾讯云注册，且已完成备案**
- 之前我按「腾讯云服务器」写的流程**是错的**

### 这带来一个真实的额外步骤：**接入商变更**
ICP 备案是「主体 + 域名 + **接入服务商**」三绑定。
备案在腾讯云下，但服务器在阿里云 → **阿里云侧没有接入记录**。

**后果**：
阿里云的 ECS 会拦截「未在阿里云接入备案」的域名的 **80/443 访问**。
表现是：域名解析没问题、Nginx 配好了，但**外网访问 403 或直接断**。

### 必须做的：在阿里云做「新增接入」
1. 阿里云 → 备案控制台 → **「新增接入」**（不是「新增网站」）
2. 填已有的备案号（腾讯云那边拿）
3. 阿里云会重新核验一次（身份证 / 人脸）
4. **不需要重新走 7–20 天全流程**，接入审核通常 **1–3 个工作日**

### 🔴 但这里有个更大的问题
**如果 dorjea.cn 还没备案 —— 那要先在腾讯云做「新增网站」拿到备案号，
再到阿里云做「新增接入」才能用。**

**两步串行，不是并行。** 顺序不能反。

### 时间估算
```
腾讯云「新增网站」dorjea.cn:   7–20 工作日
阿里云「新增接入」：            1–3 工作日
──────────────────────────────────
合计最少:                      8–23 工作日（约 2–5 周）
```

### 教训（重要）
**「grep 只找到注释引用」不等于「门禁不读」** ——

**判断「能不能删」必须同时做：**
1. grep 字面量
2. **实际跑一遍门禁**（这才是唯一可信的）
